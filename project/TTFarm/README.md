# TT农场（TTFarm）

浏览器 3D 农场经营小游戏：开地、买种子、播种、浇水、收获、卖菜。
游戏以 Three.js 渲染，由作品集主站提供账号和存档接口，生产入口为 `/ttfarm/`。

## 账号、昵称与好友

- 输入用户名登录或创建农场。进入游戏前，首次使用的账号和昵称为空的老账号需要取一个全服唯一的昵称。已有昵称的玩家登录后直接回到农场。
- 游戏内的头像栏、排行榜、好友申请和来访名单均显示昵称。点击头像，在「个人资料」中可以改名。改名后原有好友关系和协作授权继续有效。
- 在「好友」中输入对方的昵称搜索并发送申请。对方接受后可以串门，同场可见彼此的位置、服装和坐骑。农场主可以在对应好友的昵称旁开启或收回协作权限。授权后的好友可以播种、浇水、收获和驯服野生动物，消耗与收成都归当前农场。

## 操作与种植

- 电脑端用 WASD 或方向键移动，按住 Shift 奔跑，空格跳跃。按住鼠标左键或右键拖动即可转镜头，也可用 Q / E 左右环绕。滚轮缩放，R 或双击场景复位。
- 触屏左侧摇杆控制方向和常速，点摇杆右侧的「冲刺」切换加速，再点恢复常速。按住摇杆时可用另一根手指在画面上拖动转镜头或按右侧按钮跳跃。在画面上双指捏合缩放。
- 选好种子后走上已开垦的空地，点「撒种」即可种菜。也可以轻点地块让人物自动走过去。走上已有作物的地块可以浇水，每茬最多三次。成熟后作物上方会出现麦穗标志，走上对应地块即可点击收获。
- 30 块地从第一排开始扩建。晴天、多云、阵雨、雪天、大风、雷雨和大雾每 3 分钟随机换一次，刷新或换设备后仍是同一场天气。阵雨和雷雨中播种自带一次浇水。「农场 → 田间气象」会显示当前变异概率、偏向的元素和下场天气。
- 每种天气都可能种出六种元素变异。雷霆、冰霜、神火按原价 2 倍出售，黄金 3 倍，大地气息和风之息 5 倍。变异中还有 10% 的机会长成五位 Q 版精灵之一，售价为 8 倍。种下时确定品种，收成按作物和变异分别入库。已有金穗、雾晶和雨珠仍按原价目结算。
- 登录后进度同步到 PostgreSQL。浏览器保留本地进度，种下的变异品种在刷新或跨设备读取存档后继续生长。
- 点击金币框左侧的奖杯查看本服农场主的金币前十，同分并列。点榜上的农场主可以用自由镜头参观农田和牧场，WASD 或摇杆平移镜头，拖动环绕，滚轮或双指缩放。
- 点击头像进入角色衣橱，可以在小穗和青禾之间切换。选中套装会换上整套服饰，也可以单独搭配下装和鞋靴。点击「穿戴并保存」后在场景中生效。
- 「农场 → 庭院装饰」中提供三种带光效的套系，可混搭围栏、门、牌匾和字体，并设置最多 12 个字的招牌。角色穿搭和庭院装饰均随账号存档。
- 沿河岸走进浅水可以涉水，进入深水自动切换蛙泳，松开方向键或摇杆会原地踩水。也可以点选水面或对岸。木桥从两端坡道上桥，河中央可以从桥下游过。
- 靠近河岸或木桥可以听见流水声。阵雨、雷雨和大风带有对应的环境声，可在操作说明中分别切换流水声和天气声。

## 钓鱼

- 鱼竿在「商店 → 装备」购买，在「背包 → 装备」点击装备。溪竹竿为初始竿，青锋溪流竿 Lv4、灵纹鲤竿 Lv8、沧海玄竿 Lv12 才能购买；越高级抛得越远、拉鱼高亮区越宽。
- 装备鱼竿后走到河岸，右下角才出现钓鱼按钮。点击抛竿，鱼钩落到水面，浮漂会随机轻点；真正咬钩时浮漂下沉或上浮巡游，5 秒内必须提竿，否则脱钩。钓鱼按钮左侧的小按钮用来选择鱼饵。
- 鱼饵在「商店 → 杂物」购买，8 种鱼饵对应不同的稀有度权重和目标鱼种。咬钩时消耗一枚鱼饵；仓里没有鱼饵也能抛竿，但浮漂始终不会有鱼咬。选择「不用鱼饵」同样可以抛空钩。
- 提竿后进入遛鱼：小球在亮条内左右往返，金色高亮区随机生成。鱼越贵，高亮区越窄、小球越快；30 秒内在小球进入高亮区时点「起竿」才能钓上，点错或超时都会脱钩。
- 河里有 50 种鱼沿河自由游动，另有常见鱼群集中在农场河段。渔获弹出卡片，展示体长、估重、售价、鱼篓数量、简介与用途；成功后同时点亮图鉴并存入背包「鱼篓」。
- 抛竿、落水、咬钩、卷线、断线与成功都有程序化音效，角色会切换抛竿、持竿、遛鱼动作。咬钩时提竿按钮会亮橙红闪烁、鱼图标摆动，并弹出「咬钩！」徽章；手机右下角操作簇为半透明磨砂玻璃。

## 雨后菌季与百种蘑菇

- 阵雨或雷雨结束后的下一个天气阶段，野外会长出蘑菇；如果雨后紧接着下雪，这一季直接没有菌。菌季只持续一个天气阶段，下一阶段自动收菌，下一场雨再来。
- 共 100 种菌，长在倒木、树桩、枯树干、灌木和草坡上，树干菌可以长到两三米高。走近后出现菌类采集卡，显示菌名、稀有度、宿主、价格和变异；采摘得金币、经验和图鉴记录。
- 「图鉴 → 菌类」收录 100 种，支持搜索和只看已收集。
- 三种菌类变异：**魔气**（暗紫透明雾裹着菌体，雾里有 Q 版骷髅虚影绕行）、**氤氲**（七彩透明雾与菌顶小彩虹）、**通灵**（外观不变，隔一阵冒吐槽气泡，每 10 秒沿宿主挪一步）。
- 地图上出现非五行普通变异的作物时，顶部会弹一条金黄透明流光提示，橙字播报「出现了「xxx」」。

## 牧场与野生动物

- 农场正门外的牧场从 1 级开始，占用 1 个栏位可收留 1 只动物。初始容量为 4，每级增加 2，最高 10 级可收留 22 只。「牧场 → 前往牧场」会自动寻路到栏门。
- 野外每 12 分钟刷新一批动物，从 20 种中选出 12 种。「牧场 → 寻找野生动物」可以带路。靠近后，从仓库中选择已收获的作物投喂。普通动物需要一份，五行变异动物吃一份喜爱的作物或两份其他作物，收服后自动进入牧场。
- 野生动物每轮会换空地，刷新位置不再固定。所有动物都会持续随机漫游，不会长期站在同一点；落点限制在活动半径内，靠近水线会被推回岸上。收服后的动物放养、出栏或卖掉后，不会重新出现在原来的收服位置。
- 野外地面加入低矮土丘和多种轮廓的石头，不再是一整片平地。
- 牧场达到 3 级后，已收服的野马，以及五行变异的狼、熊、虎、狮子、大象和熊猫都会进入独立坐骑栏。点击「骑乘」即可出发。普通马和变异马的骑行、奔跑速度均为其他坐骑同档的 3 倍，奔跑时身后会留下彩色流光。点击「下坐骑」或进入深水后，坐骑会回栏。

野外的 20 种动物中，14 种使用 Wildfire Games 为《0 A.D.》制作的骨骼模型。灰狼、棕熊、老虎、狮子、大象、赤狐、野兔、野猪、山羊、绵羊、野马和花牛采用 codepawl 转换的 GLB。大熊猫沿用棕熊的网格、骨骼和毛皮底纹，重塑身体比例并重绘黑白被毛。梅花鹿则由原作的鹿身、鹿角和贴图重新绑定骨骼。这 14 种模型的改编均沿用 CC BY-SA 3.0 许可。游戏中可在「操作说明」底部查看模型来源。[动物模型署名与许可](public/credits/animals.html)

羊驼、浣熊、小熊猫、企鹅、绿头鸭和丹顶鹤使用 TT 农场原创模型。

小穗的走、跑、跳取自卡内基梅隆大学的真人动作捕捉数据。环境声采用 jackthemurray 和 Borgory 发布的 CC0 实地录音，随游戏打包。[动作来源与生成方式](src/scene/MOTION-CREDITS.md) · [溪流录音](https://freesound.org/people/jackthemurray/sounds/433589/) · [雨声录音](https://freesound.org/people/Borgory/sounds/678435/)

## 野菜与阴阳 / 长生变异

- 作物扩充到 24 种农田作物：原有 6 种之外新增茄子、豆角、辣椒、西瓜、桃子、梨、杏、枣、郁金香、百合、菠萝、榴莲，以及红 / 粉 / 白 / 黄 / 蓝 / 紫六色玫瑰，等级上限扩到 12 级。
- 野外每 10 分钟长出一批 28 丛野菜（20 种：荠菜、蒲公英、马齿苋、蕨菜、香椿、榆钱、槐花、灰灰菜、野苋菜、车前草、鱼腥草、野薄荷、紫苏、艾草、野葱、野蒜、水芹菜、蒌蒿、马兰头、菊花脑）。走近点「采摘」获得野菜，35% 概率捡到种子；野菜种子商店不卖，只能捡回来种。「农场 → 野外野菜 → 去寻找」自动带路到最近的菜丛。
- 约一成野外菜丛自带变异，采到直接入库变异收成。野菜只会发生两种变异，各三级：**阴阳**（植株半黑半白，白气与黑气对流，1 / 2 / 3 颗柔光星辰环绕，售价 ×4 / ×8 / ×16）与**长生**（植株玉质化，翡翠云雾与柔光玉柱，1 / 2 / 3 条小金龙环绕，售价 ×5 / ×10 / ×20）。种下野菜种子有 14% 概率抽中变异，级别概率 68% / 25% / 7%。普通作物不会抽到阴阳 / 长生，野菜也不会抽到元素 / 精灵，错配存档会被洗掉。
- 采摘记录（`forage` 字段：刷新轮次 + 已采编号）随存档入库，换轮自动重长；旧客户端不带该字段时服务端保留原记录。特效走独立的柔光粒子系统（`src/scene/wildAuras.ts`）：大面积低透明度光晕、慢速呼吸，不用亮线条。

## 角色动作

- 7 个动作：出拳（J）、踢腿（K）为一次性打击动作；欢呼（C）、跳舞（X）、坐下（Z）、躺下（V）、晕倒（B）持续到主动取消。左上角「动作」按钮打开弹层点选，与键盘等价；移动、跳跃、下水、骑乘会自动取消动作。
- 动画挂在共享姿态采样器末尾（`src/scene/actionMotion.ts` 关键帧 + 程序化叠加：欢呼挥手小跳、跳舞摆胯点头、晕倒倒地后眩晕抽动），低模骨架与 VRM 形象同时覆盖；出拳时 VRM 手指握拳。躺 / 晕用额外 lift 让躯干贴地不穿模。
- 动作随在线状态同步给好友：`SocialPose` 增加 `action / actionTime`，服务端 heartbeat 白名单校验（非法值洗成 null），好友端在心跳间隔本地推进动作时钟并按同一权重曲线淡入淡出。

Three.js + TypeScript + Vite + Zustand + React（仅 DOM 覆盖层 UI）。**不单独起容器**：静态产物并入作品集主站。

## 目录结构

```
TTFarm/
├── docs/          # 设计与技术文档
├── src/           # 源码（game 纯逻辑 / scene 渲染 / ui 面板）
├── scripts/       # sync-to-site.mjs：把 dist 同步进主站 public/ttfarm
└── public/        # 静态资源（4 张角色头像 avatars/、4 张角色贴图 textures/）
```

## 本地开发与发布

不再在宿主机装 Node / pnpm，游戏和主站一起跑在 `lzh_show_frontend` 这个容器里：

```bash
# 在仓库根目录执行（首次构建较慢）
docker compose up -d frontend

# 游戏开发地址 http://localhost:5174/ttfarm/ （Vite，改源码自动热更新）
# 主站地址     http://localhost:3100
docker logs -f lzh_show_frontend    # 两个进程的日志都在这里
```

- 依赖只存在容器内（`/ttfarm/node_modules`、`/app/node_modules` 是匿名卷），宿主机不留 `node_modules`
- 已有开发数据库可在仓库根目录用 PowerShell 运行 `Get-Content -Raw project/TTFarm/db/schema.sql | docker exec -i shared-postgres psql -U ttfarm -d ttfarm -v ON_ERROR_STOP=1` 升级。部署工作流会自动应用同一份幂等结构脚本。
- 镜像重建（重装依赖）：`docker compose build frontend` 后 `docker compose up -d frontend`
- 发布：产物由镜像的 builder 阶段自己构建（`vite build` → `public/ttfarm`），随主站镜像一起发布，**不需要本地构建、也不需要 `sync-to-site`**
- `scripts/sync-to-site.mjs` 仅作为手动同步的备用手段保留（需要本机有 Node 才能跑）

发布链路：提交源码 → GitHub Actions SSH 进服务器 → `git reset --hard origin/main` → `docker compose -f docker-compose.prod.yml up -d --build`。游戏是主站的一次静态发布，**同域名、同端口、同容器**；`blog_front/src/proxy.ts` 负责把 `/ttfarm`、`/ttfarm/` 改写到 `/ttfarm/index.html`（该路径不参与 next-intl 语言路由）。

`vite.config.ts` 里 `base: "/ttfarm/"`，所有资源路径自带子路径前缀，因此主站不需要任何 nginx 额外配置。
