# 第十一轮：河东大城实机修复

基线：第十轮 `0a47ae1`。本轮只修上线后暴露的七项实机问题，不新增经营系统。

## 1. 汽车店东立面玻璃墙挡人

根因有两层：

- 北门 `doorX = 72.6` 是世界坐标，却被直接当成店铺本地坐标，北面玻璃分割和门贴整体错位。
- 东立面是整墙玻璃加整段碰撞，从中央街方向没有任何门洞。

修复：

- `townDealership.ts` 统一换算为本地坐标：`doorCX = doorX - DEALERSHIP.x`、`eastDoorCZ = eastDoorZ - DEALERSHIP.z`。
- `DEALERSHIP` 增加 `eastDoorZ = 41.4`、`eastDoorWidth = 2.4`。
- 东立面拆成门洞南北两段玻璃和两段碰撞，门洞净宽 2.4m；补东门迎宾石、自动门扇、`自动门 ENTER` 门贴。
- 店内展车改为城市轿车 / 旅行车 / 跑车三种轮廓。

实机：自动导航到东门后 `townAction = 星野汽车 · 看车 / 购车`，人物可穿过门洞进店。

## 2. 车辆只在城里开，过桥车只去售货铺

根因：旧 `Lane/Traffic` 按轴固定车道，越界后直接瞬移回起点，看起来会乱开、突然出现。

修复：

- 删除旧车道系统，改为 5 台 `RouteCar` 沿 `CITY_LOOP` 闭环行驶：中央街 → 主大道 → 东街 → 北大道，闭合 `CatmullRomCurve3` 平滑转弯，不瞬移、不越桥。
- 新增唯一过桥车 `DeliveryVan`：城市主大道 `(52,52)` → 桥东 `(43,52)` → 桥心 `(30.5,52)` → 桥西 `(21,52)` → 河岸步道 → 售货大厅北门外 `HALL_PARKING (24.2,19.6)`。到店停 11 秒，再原路返回；城端停 5 秒。

参数集中在 `townLife.ts` 顶部：`CAR_CRUISE = 3.1`、`DELIVERY_SPEED = 2.5`、`SHOP_PARK = 11`、`CITY_PARK = 5`。

## 3. 桥与城市入口主大道同宽对齐

根因：桥由河道采样点求心，桥心约 `(29.96,49.58)`，与主大道 `z = 52` 差约 2.4m，半宽 3.4 与主大道 3.6 也不一致。

修复：`layout.ts` 的 `BRIDGE` 改为固定值：

```ts
{ x: 30.5, z: 52, nx: 1, nz: 0, deckY: 0.62, rampLength: 3.0, halfLength: 9.6, halfWidth: 3.6 }
```

桥面总宽 7.2m，与 `AVENUES.main` 的 `half: 3.6` 一致；东坡道端点约 `x = 43.1`，主大道起点 `x = 42.6`，重叠 0.5m 接上。`SHOPPER_ROUTE` 的桥面段改到 `z ≈ 52`。

## 4. 河对岸半城没建筑

在 `townLayout.ts` 补齐东街窄街区与北城：

- 塔楼：`tower-east-a (134,25,7,5,27)`、`tower-east-b (134,91.5,7,5,29)`。
- 中层：`mid-east-a (134,31.5,6,5,14)`、`mid-east-b (134,85.5,6,5,15)`、`mid-east-c (133.5,120.5,6,6,14)`、`mid-east-d (133.5,134,6,6,16)`、`mid-north-w (48,128,6,7,15)`、`mid-north-e (122,131,6,6,15)`。
- 门店：`shop-east-c (134,80,4,3.5)` 东街水果、`shop-east-e (134,127)` 东街小铺、`shop-north-w (48,136)` 北门花店、`shop-south-e (118,27)` 南街茶点。

东街 x126~140 从原来的 3 店 1 楼补成连续沿街立面；同时收掉与 `mid-east-d` 重叠的 `garden(136,128)`，避免树穿楼。

## 5. 汽车店找不到

- 新增 `game/townNav.ts`（zustand）：每 0.22s 写玩家 / 车辆坐标，城里或桥面显示导览卡。
- `TownHUD` 显示「星野汽车 {distance}m · {方向}边」，带「带我去」；`DriveDock` 空车库也有「带我去星野汽车」。
- 导航分两段：先走到东门外人行道 `(77.55,41.4)`，到点后再走进门内 `(75.55,41.4)`。第一段走完整桥路，第二段只穿门洞，避免从农场直线切河，也避免到达时第三人称镜头卡进店墙。
- 店外新增三处找店信号：城门内侧 `(49,57.8)` 的「星野汽车 → 中央街」路牌；东门玻璃上的大字「星野汽车」；门旁悬挑双面灯箱和人行道 A 字看车牌。
- 东门旁增加立牌碰撞，人物不会再穿过广告牌。

实机：从农场点「带我去星野汽车」，约 58 秒沿主大道到东门，自动进店，`townAction` 打开购车面板。

## 6. 玩家车辆重做

`townCar.ts`：

- 三套比例 `city / tourer / sport`，车身用侧面轮廓 `ExtrudeGeometry` + 圆角倒角。
- 补齐轮眉黑色衬里、裙边、前铲、后扩散器、车门缝、把手、后视镜、油箱盖、牌照。
- 座舱用 A/B/C 柱 + 车顶 + 透明侧窗 + 前 / 后风挡；新增 C 柱侧板，侧面不再是「一整块玻璃通到车尾」。
- 内饰：仪表台、双座椅、头枕、方向盘，驾驶员有头发、脸、眼睛、鼻尖、躯干、搭在方向盘上的手臂、坐姿双腿和鞋；低顶跑车整体下沉 0.18m，头部不穿车顶。
- 玻璃改为 `opacity 0.14` 的清透材质，从侧窗和风挡都能看到驾驶员。
- 轮组重做：胎体 + 两侧胎壁 + 银色轮圈外沿 + 刹车盘 + 五根单向细辐条 + 中心盖 + 卡钳；四个轮子独立，前轮随转向摆动，行驶时绕轮轴旋转。

实机：城市轿车、旅行车、跑车三款均能看清透明玻璃、驾驶员和五辐轮毂。

## 7. 手机发言键压跳跃键

`styles.css` 在 `max-width: 820px` 把 `.chat-dock` 底边从 86px 抬到 `calc(166px + safe)`，横屏低高度 116px；`town.css` 的导览卡在窄屏移到顶部。

390×844 与 844×390 触屏视口实测：

- 竖屏：发言 `y 582–678`，跳跃 `y 693–759`，不重叠。
- 横屏：发言 `y 202–298`，跳跃 `y 310–376`，不重叠。
