# TTFarm 第十轮迭代计划 · 河东大城、河岸售货大厅与驾驶

> 目标：把桥东小城扩成铺满河对岸的城镇，木桥改水泥桥；农场东侧临河建可进入的售货大厅，玩家可卖蔬菜和动物肉，城里 NPC 会过桥来买；城镇建筑、NPC、车辆建模升级，新增可进入的 24 小时便利店与可买车、可驾驶的汽车店；发言按钮上方加驾驶入口。
>
> 执行顺序：Q0 坐标与数据定稿 → Q1 水泥桥 → Q2 大城路网与建筑扩容 → Q3 可进入建筑与内饰 → Q4 售货大厅与肉品链路 → Q5 NPC 消费与车辆升级 → Q6 购车 / 驾驶 / UI → Q7 全量验收与交付。

### 驾驶

- 车行目录 3 款：`城光`（紧凑轿车，1200 金币，极速 13m/s）、`远山`（旅行车，2200 金币，极速 15m/s）、`赤陶`（跑车，3600 金币，极速 18m/s）。
- 每台车可选 6 种车漆；购买后写入存档 `garage`，带车牌号。
- 发言按钮上方新增「驾驶」按钮；点开列出已拥有车辆，选择后车辆出现在玩家前方 3m，人物隐藏，相机跟随车辆。
- W/S 油门/倒车，A/D 转向，Shift 加速，Space 手刹；「下车」或再次点驾驶按钮退出。
- 车辆受建筑、树木、路灯碰撞约束；不能开进河，过桥时贴合桥面高度。

## 2. 关键设计

- **路网扩容不推翻旧城**：保留旧城 4 高楼、3 中层、11 门店与现有坐标；把主大道向东延到 140，中央街向北延到 140，再补北大道 z=110 与东街 x=126，形成 4 个十字路口。北城与东街新增建筑填满空地。
- **可进入建筑**：前墙拆成「左玻璃 + 门洞 + 右玻璃 + 门头」，门洞不注册碰撞；侧墙、后墙分段注册。室内地板与街区铺装同高，玩家直接走进去，不做读条/传送。
- **售货大厅**：位于草地与河坡交界，混凝土台架空到河坡上，东面整幅玻璃看河。蔬菜和肉品走同一个柜台面板，按品类分栏。
- **肉品链路**：牧场面板新增「出栏」按钮，动物转为肉品库存（按物种命名，如花牛→牛肉、绵羊→羊肉），不再直接卖活体；肉品在售货大厅按份卖出。原有「卖出」保留为活体直卖，价格略低。
- **NPC 消费**：城内常驻市民继续随机漫步；另设 4 名「顾客」走固定长线：城内主大道 → 桥东门楼 → 水泥桥 → 河岸步道 → 大厅门 → 收银台前停留 → 原路返回。顾客不参与碰撞，靠路线与门洞对齐避免穿墙。
- **建模升级**：建筑增加女儿墙、窗框、空调机位、檐口线脚、门口台阶与花箱；NPC 增加头发层次、围巾/挎包/帽子、手臂摆幅与身体起伏；车辆增加独立车轮（行驶时转动）、日行灯、尾灯、格栅、牌照与车型差异。
- **驾驶**：车辆不接入玩家碰撞半径，使用「车身四角采样 + 中心扫掠」判定；桥面用 `bridgeHeightAt` 抬升，河面除桥外禁止驶入；相机沿用现有环绕相机，焦点换成车辆。
- **性能**：建筑仍按单体 merge（每栋 2~3 draw call），新增内饰独立小网格；NPC 每人 2 个网格，车辆 NPC 每台 1 个网格。地面常态目标 ≤450 draw calls，高空 ≤750。

## 4. 验收标准（逐条可测）

1. **城市规模**：桥东城镇覆盖 x 44~140、z 22~140；站在桥头能看到连续街区铺到远处山脚，不再是一小片孤城。
2. **路网**：两条东西向大道 + 两条南北向街道正交，形成 4 个十字路口；每个路口有斑马线、路缘、信号灯；路面不压河、不悬空。
3. **建筑密度**：高楼 ≥7 栋（≥20m），中层 ≥6 栋，平房门店 ≥19 家；北城与东街无大片空铺装。
4. **水泥桥**：桥面为混凝土材质，有伸缩缝、混凝土栏杆基座、金属护栏、桥墩与桥灯；桥上无木板；行人与车辆都能过桥。
5. **售货大厅**：位于农场东侧临河，可从北门走入；室内有蔬菜货架、肉品冷柜、收银台；靠近柜台能打开面板，蔬菜和肉品都能卖出并到账。
6. **肉品**：牧场动物可通过「出栏」转为肉品库存；肉品有独立名称、份数与售价；售货大厅可卖出。
7. **NPC 消费**：≥4 名顾客从城内出发，过桥进入售货大厅，在柜台前停留后返回；路线不穿墙、不落水。
8. **24H 便利店**：≥2 家可进入；门洞净宽 ≥1.8m；室内有货架、冷柜、收银台与照明；玩家能走进去再走出来。
9. **汽车店与购车**：汽车店可从北面玻璃门进入；店内有 ≥3 台展车与接待台；靠近后能打开购车面板，扣金币后车辆进入车库并持久化。
10. **驾驶**：发言按钮上方有「驾驶」按钮；点开显示已拥有车辆；选择后人物隐藏、车辆出现、相机跟随；W/S/A/D 可驾驶，Shift 加速，Space 手刹；能下车；不能开进河，过桥贴合桥面。
11. **建模**：建筑有窗框、女儿墙、檐口、空调位等细节；NPC 有头发/配饰/手臂；车辆有独立车轮、灯具、牌照；近景无明显几何拼凑感。
12. **工程与性能**：前后端 `npx tsc --noEmit` 通过；`npx vite build` 通过；`sync-to-site` 成功；浏览器无报错；地面常态 draw call ≤450、高空 ≤750；README 追加记录；提交并推送 main。

## 5. 风险与对策

| 风险 | 对策 |
|------|------|
| 大城扩容后树石/野花穿进街区 | `inTown()` 扩到新边界；所有散布统一走排除函数 |
| 可进入建筑门口被碰撞堵死 | 碰撞按墙体分段注册；门洞前后各留 0.5m 净空；用实测走位验证 |
| 售货大厅压到河坡/水面 | 先探测河岸距离，基座架空 + 混凝土台；东墙不越过 waterline |
| 顾客过桥穿模/落水 | 固定路线沿桥面中心与河岸步道，不走车道；桥面高度按 `bridgeHeightAt` |
| 驾驶穿建筑 / 开进河 | 车身四角采样 + 河面禁止区；桥外 `riverInfo.dist < shoulder` 直接拒绝位移 |
| 新增建筑导致 draw call 过高 | 单体 merge；重复路灯/树/长椅合并；内饰只保留必要网格 |
| 存档新增字段导致旧档丢失 | `merge` 中给 `meat`、`garage` 默认值并做归一化 |

## 6. 实机结果（2026-11-22）

- **山体越界返工**：东侧山脊原基座 x≈124，压住城市最东一排门店与 24H；`world.ts` 将东侧山线整体后退 34m，城市 x~140 完整露出，店铺门口不再被山体吞没。
- **信号灯合批**：4 路口 ×4 柱 ×3 灯的 48 个镜片改为「方向 + 灯色」6 个 InstancedMesh，路口灯色仍按 18s 相位变化。
- **建筑合批**：全城 8 高楼 + 7 中层 + 25 门店 + 汽车店 + 2 便利店的实心 / 玻璃 / 墨线按材质各并为 1 张网格，招牌与店内动态陈设保留独立。
- **性能**：同一高空机位 draw call 831 → **525**，实测帧率 20 → **41fps**；农场默认视角 343。地面常态低于 450。
- **驾驶**：桥头 x40 上车、W 直行 3.2s 到 x-2.3，完整通过水泥桥；下车人物出现在车侧 2.4m；桥头车层统一切换后不再卡在桥端。
- **售货**：柜台面板蔬菜 6 批共 1563 金币；肉品「花牛肉」×4、59 金币/份，卖出全部 +236 到账。
- **购车**：汽车店面板 3 车型 6 车漆，4000 测试金币提「赤陶」3600，车库 2/6、车牌 `京A·T02`，持久化正常。
- **收尾**：测试金币 / 车库 / 肉品已恢复原档（1031 金币、0 车、空冷柜）；`__ttfarmDev` 调试钩子与 `_river_probe.mts` 已删除。
