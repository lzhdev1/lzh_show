# 第十四轮：顶部按钮重排

基线：第十三轮 `ed4356d`。本轮只调整 HUD 入口位置，不改功能。

## 1. 商店从菜单移到顶栏

- `App.tsx` 的 `menuItems` 删除「商店」。
- 顶栏商店按钮去掉 `hud-compact-hide`，窄屏也会显示；宽屏显示 `ShopIcon` + 「商店」文字，`<=560px` 收成图标按钮；保留 `aria-label="打开商店"`。
- `HudMenu` 注释同步更新：菜单只留图鉴、排行、好友、天气 / 农场、动作、操作说明与返回登录。

## 2. 农场移到牧场旁边并保留文字

- 顶栏原「农场」按钮移除。
- `field-status` 的行内新增 `farm-trigger`，紧挨 `RanchTrigger` 左侧：
  - 复用 `.ranch-trigger` 的 44px 高度、14px 圆角与图标 + 文字结构；
  - 文字固定为「农场」，不再受 `.icon-btn.labeled span { display:none }` 影响；
  - 单独用浅绿底与深绿字区分农场 / 牧场。

## 3. 驾驶与发言移到顶部

`styles.css` 的 `.chat-dock` 从右下角改成顶部第二行：

- `top: calc(75px + safe-area-inset-top)`，`bottom: auto`。
- 横排：左侧 `DriveDock`（驾驶 / 结束驾驶），右侧 `发言`。
- `.chat-card` 改为绝对定位，从按钮行下方展开，不再把按钮组向上顶。
- 窄屏 `<=560px` 顶部对齐到 `60px`；触屏横屏低高度对齐到 `64px`。

最终主界面：

- 第一行：头像 / 昵称、金币、商店、菜单。
- 第二行左侧：农场、牧场。
- 第二行右侧：驾驶、发言。
