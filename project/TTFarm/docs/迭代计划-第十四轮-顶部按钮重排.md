# 第十四轮：顶部按钮重排

基线：第十三轮 `ed4356d`。本轮只调整 HUD 入口位置与功能菜单层级，不改玩法。

## 1. 商店从菜单移到牧场右侧

- `menuItems` 删除「商店」，菜单只留图鉴、排行、好友、天气 / 农场、动作、操作说明与返回登录。
- 初版把商店放在顶栏第一行；实机验收时顶栏右侧过挤，改为放进 `field-status`，紧挨 `RanchTrigger` 右侧：
  - 复用 `.ranch-trigger` 的 44px 高度与 14px 圆角；
  - `ShopIcon` + 「商店」文字始终可见，不再受 `.icon-btn.labeled span { display:none }` 影响；
  - `.shop-trigger` 用浅暖底、深褐字，与农场浅绿、牧场奶白区分。

## 2. 农场移到牧场旁边并保留文字

- 顶栏原「农场」按钮移除，`field-status` 内按「农场 → 牧场 → 商店」排列。
- 农场复用 `farm-trigger` 浅绿皮肤，文字固定为「农场」。

## 3. 驾驶与发言移到顶部

`styles.css` 的 `.chat-dock` 从右下角改成顶部第二行：

- `top: calc(75px + safe-area-inset-top)`，`bottom: auto`。
- 横排：左侧 `DriveDock`（驾驶 / 结束驾驶），右侧 `发言`。
- `.chat-card` 改为绝对定位，从按钮行下方展开，不再把按钮组向上顶。
- 窄屏 `<=560px` 顶部对齐 `60px`；触屏横屏低高度对齐 `64px`。

## 4. 功能菜单脱离顶栏层叠上下文

实机复现：菜单展开后被农场、牧场、驾驶、发言压住。根因是 `.topbar { position: fixed }` 自身形成层叠上下文，菜单的 `z-index: 55/56` 只在顶栏内部比较，压不过后面的 `.field-status` 与 `.chat-dock`。

- `HudMenu` 打开态用 `createPortal` 把遮罩与面板渲染到 `document.body`，直接参与根层叠；菜单按钮仍留在顶栏。
- 面板改为从第二行下方展开：桌面与平板 `top: 128px + safe-area`，`<=560px` 为 `112px`，触屏横屏低高度为 `116px`。
- 第二行按钮底边实测约 `119px`（驾驶 / 发言约 `121px`），菜单改为 `128px` 起，不再与按钮重叠。
- `<=560px` 时农场、牧场、商店收成图标在上、文字在下的 44px 竖排按钮，三个并排仍不与右侧驾驶 / 发言挤压。

最终主界面：

- 第一行：头像 / 昵称、金币、菜单。
- 第二行左侧：农场、牧场、商店。
- 第二行右侧：驾驶、发言。

- `node scripts/sync-to-site.mjs` 同步到 `blog_front/public/ttfarm`。
- 浏览器实测（805×775）：
  - 第二行左起「农场」「牧场」「商店」，商店带文字且可直接打开商店面板；
  - 菜单遮罩覆盖全屏，面板从 `128px` 开始，完整盖在按钮之上，驾驶 / 发言不再压住标题栏；
  - 菜单 `parentElement` 为 `BODY`，`z-index` 56；第二行按钮底边 `119–121px`，无重叠；
