# 修复桥面驾驶时车辆被埋进桥体

## 现象

驾驶车辆驶上河东大桥后，车身下半部分进入桥面，看起来像被桥“埋住”。桥中央最明显，桥头坡道也会出现车身突然下沉。

## 根因

车辆每帧贴地只调用了 `fieldHeightAt`：

```ts
vehicle.update(..., fieldHeightAt);
```

`fieldHeightAt` 覆盖农场草台与土垄、售货大厅、停车场和城镇铺装，但桥面和两端坡道是独立于地形高度的抬升面，由 `bridgeHeightAt` 计算。桥面高度为 `BRIDGE.deckY = 0.62`，车辆中心却在桥面时仍取草地高度 0，于是车身下沉约 0.62m。

另外两处也有同一根因：

- 在桥上直接上车时，`PlayerVehicle` 构造函数把初始 `root.position.y` 固定为 0，第一帧就埋在桥里。
- 在桥头坡道下车时，`stopDriving` 只用 `onBridge` 判断中央桥面，坡道会被当普通地形处理，人物落点高度可能对不上坡面。

步行角色没有这个问题：`Player` 用 `onDeck` 状态，进入桥面或坡道后由 `sampleTravelSurface` 调 `bridgeHeightAt`，所以人物能沿桥面与坡道起伏。

## 修复

1. `loop.ts` 新增 `vehicleHeightAt(x, z)`：

   ```ts
   Math.max(fieldHeightAt(x, z), bridgeHeightAt(x, z) ?? -Infinity)
   ```

   普通地形与桥面/坡道高度取较大值。取较大值同时处理桥东坡道末端与城镇铺装之间约 0.1m 的接缝，避免坡道高度归零时车辆突然下沉。

2. 车辆构造与每帧更新都改用 `vehicleHeightAt`，上车第一帧不再从 y=0 开始。
3. `PlayerVehicle` 构造函数新增 `surfaceY` 参数，根节点初始高度由调用方按当前位置计算。
4. 桥头坡道给车身加俯仰：按车头方向在桥轴上的投影计算抬头/低头，桥面中央保持水平；倾角封顶 `MAX_RAMP_PITCH = 0.24`，避免贴边转向时夸张倾斜。
5. 下车判定改为 `bridgeHeightAt(want.x, want.z) !== undefined`，坡道也按 deck 层投影与 `relocate`，人物落点高度对齐坡面。

## 其他有高低差的路面

已逐项核对可驾驶区域：

- 农场草台、地块土垄：`fieldHeightAt` 覆盖。
- 售货大厅混凝土台：`salesHallHeight` 覆盖。
- 大厅旁停车场：`hallParkingHeight` 覆盖。
- 河东小城人行道、广场、车道：`townSurfaceHeight` 覆盖。
- 河道深水：车辆 `allowed` 直接拦截，不能开入。

因此目前明确缺失的是桥面与两端坡道。其他抬升路面原本就在车辆贴地函数内。

## 验证

- `pnpm typecheck` 通过。
- `pnpm build` 通过，产物入口 `index-bWrs8iIB.js` / `index-Cact2lF-.css`，游戏 chunk `loop-DC5ZIxii.js`。
- 开发服实测：
  - 桥面中央 (30.5, 52)：车轮落在桥面，车身不再下沉。
  - 桥西坡道 (19.4, 52)：车头抬头，车身沿坡面。
  - 桥东坡道 (41.6, 52)：车头低头，接上城镇道路。
  - 从坡道驶入桥面：连续行驶无突然下沉或弹跳。
  - 桥上重新上车：构造高度正确，不出现第一帧埋车。
  - 坡道停车下车：人物 y 与 `bridgeHeightAt` 一致（实测 0.31m）。
