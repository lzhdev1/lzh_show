## 1. 关键设计决策（默认方案，可改）

### D1 草药是新类别，不是野菜
- `CropDef` 新增 `herb?: true`；`CROPS` 增加 50 条；`CropId` 并入 `HerbId`。
- 草药不进商店（`SHOP_CROPS` 只排除 `wild`，需同时排除 `herb`），种子只能野外采摘获得。
- 与 `wild` 的区别：变异规则不同、售价档位不同、图鉴独立页签。

### D2 草药变异：五行 + 仙品 + 神品（新增 7 个 Mutation）
- `herbMetal / herbWood / herbWater / herbFire / herbEarth` → 金品 / 木品 / 水品 / 火品 / 土品，倍率 4 / 4 / 4 / 5 / 5。
- `xianpin` 仙品 ×15；`shenpin` 神品 ×30。
- 命名加 `herb` 前缀，避免与现有 `gold`（黄金）、`earth`（大地气息）冲突；显示文案用“金品”等，玩家不会混淆。
- `cropMutationValid` 变为三分：`herb → 7 种草药变异`；`wild → 阴阳/长生`；普通 → 元素/精灵/旧版。

### D3 野外产出复用现有 28 丛锚点
- `wildPatchesAt` 改为“野菜 + 草药”混合池：草药占 40%（约 11 丛），野菜 60%。
- 草药采摘掉种子概率 45%（野菜保持 35%）；采摘经验 +6。
- 首批野外草药丛**不带**自带变异，避免与野菜特效系统耦合；变异在播种时抽。

### D4 踢人 = 踢出当前房间
- 只允许房主踢“正在自己农场里的访客”，不解除好友关系。
- 新建 `farm_room_kicks(owner_id, user_id, until)`，踢出后 5 分钟内该访客无法重进。
- 被踢方下一次 presence 心跳收到 403 + 文案，客户端自动 `leaveVisit()` 并提示。

### D5 发言 = 房间聊天
- 新建 `farm_chat(id, owner_id, user_id, nickname, body, created_at)`，每房间保留最近 200 条。
- 进入房间拉最近 20 条；发送后本地立即上屏，1.6s 轮询补齐他人消息。
- 气泡 30 秒：本地立即显示；远端按服务器时间戳计算剩余时长。
- 历史只含玩家发言，不含“谁来串门了”这类系统消息。

### D6 移动端断点
- `max-width: 820px` 视为移动端：顶栏收敛为 `头像 + 金币`、`农场`、`牧场`、`菜单`。
- 菜单内收纳：图鉴、排行、商店、好友、动作、天气、操作说明、返回登录。
- 所有触控目标 ≥ 40px，按钮不重叠、不遮摇杆。

### D7 牧场售价
- 售价 = 基础价（按物种）× 元素倍率（金 1.6 / 木 1.3 / 水 1.3 / 火 1.5 / 土 1.5）× 稀有度系数。
- 卖出需二次确认；坐骑被卖时同步清空 `ridingId`。

## 2. 草药 50 种清单（名称 / 建模原型）

12 个建模原型（复用 `foldedLeaf` / `stem` / `orb` 工艺，不用几何堆砌）：

- **root** 根茎型（人参、三七、天麻）
- **cap** 菌盖型（灵芝、茯苓、马勃）
- **berry** 浆果灌木（枸杞、五味子、山茱萸、女贞子）
- **umbel** 伞形花序（当归、川芎、白芷、独活、羌活、防风、柴胡、前胡、蛇床）
- **spike** 穗状花序（黄芪、甘草、丹参、黄芩、黄连、板蓝根、大青叶、桔梗、夏枯草、益母草、荆芥）
- **head** 头状花序（菊花、红花、雪莲、金盏、紫菀）
- **vine** 藤本（金银花、何首乌、石斛、菟丝子）
- **bulb** 鳞茎 / 线叶（贝母、知母、百合类药、蒜药）
- **fern** 蕨叶（贯众、骨碎补）
- **tree** 矮乔木（杜仲、肉桂、厚朴、陈皮）
- **aroid** 宽叶块根（白术、苍术、砂仁、藿香、佩兰）
- **rose** 莲座（车前子、马鞭草、地丁）

50 种：人参、灵芝、枸杞、当归、黄芪、甘草、丹参、三七、川芎、白芍、黄连、黄芩、金银花、菊花、红花、龙脑薄荷、苏叶、蕲艾、何首乌、五味子、天麻、杜仲、肉桂、茯苓、白术、陈皮、半夏、桔梗、柴胡、防风、独活、羌活、白芷、苍术、厚朴、砂仁、藿香、佩兰、香薷、荆芥、连翘、板蓝根、大青叶、夏枯草、益母草、决明子、女贞子、山茱萸、石斛、雪莲。

## 3. 执行阶段

### P1 界面快改（需求 1 / 2 / 3 / 6 / 7）
1. 种子栏排序：`filter → sort`，分组键（有种子且已解锁 = 0，有种子未解锁 = 1，无种子 = 2），组内数量降序，同数量按解锁等级、id。
2. 提示系统：`notify` 只保留最近 2 条；CSS 单条最多两行（`-webkit-line-clamp: 2`），进出用 120ms 过渡。
3. 好友农场：
   - `VisitHUD` 始终给“坐骑”入口：优先 `ridingId`，没有则自动选第一只可骑动物并 `setRiding`；无坐骑时按钮禁用并提示。
   - 把 `ActionTrigger` 搬进 visit HUD（样式适配右上/底部），确认 `loop` 在 visit 下照常上报 action。
4. 移动端菜单：新增 `HudMenu`（汉堡 + 抽屉），媒体查询隐藏桌面专有按钮；顶栏重排。
5. 牧场售卖：`animalValue` 常量表 + `sellAnimal(id)` + RanchPanel 售价/售卖按钮 + 二次确认。

### P2 房间社交后端（需求 4 / 5）
1. `db/schema.sql` 增加 `farm_chat`、`farm_room_kicks`；在 shared-postgres 容器执行（幂等）。
2. `blog_front/src/app/api/ttfarm/chat/route.ts`：GET（最近 20/50 条）、POST（校验在场/房主身份，长度 ≤ 80，1 秒限频）。
3. `blog_front/src/app/api/ttfarm/room/route.ts`：POST `{action:"kick", targetId}`，写 kick 表 + 删 presence。
4. `ttfarm-presence.ts` 心跳前检查 kick 表，命中抛 403。
5. 前端 `src/game/chat.ts`：`useChat` 状态、`pullChat`、`sendChat`、气泡队列（30s）。
6. `chatBubble.ts`：Canvas 圆角气泡贴图（多行、尾巴、名字色），本地挂 `player.root`，peer 在 `farmPeers` 内挂载。
7. UI：`ChatDock`（发言按钮 + 弹层历史 + 输入），移动端可呼出键盘；房主 `FarmGuests` 加访客列表和“请离”按钮。

### P3 草药数据层（需求 8 前半）
1. `crops.ts`：`HerbId`、`HerbDef`（50 条：名称、原型、主色、叶色、售价、生长、经验、blurb 键）。
2. `weather.ts`：7 个新变异 + `HERB_MUTATIONS`、`rollHerbMutation()`、`HERB_MUTATION_CHANCE`。
3. `crops.ts` 规则函数：`cropMutationValid` 三分支、`produceName/Price` 适配。
4. `forage.ts`：混合池 + 草药种子概率；`forageActions` 经验/掉落适配。
5. `ttfarm-save.ts`：白名单自动跟随 `CROPS/MUTATIONS`，但要检查 seeds/harvest record 是否裁剪。
6. `codex.ts`：`herb` 页签、50 条文案、7 条变异文案。

### P4 草药建模（需求 8 核心）
- `crops3d.ts` 新增 `HERB_FORM: Record<HerbId, {archetype, scale, accent}>`；
- 12 原型各写一段精细建模（花冠、花蕊、果串、菌褶、根须、叶脉细节），复用 `foldedLeaf` 的波浪边与中脉；
- stage 0/1 草药专用嫩芽（子叶 + 真叶），stage 2 未熟、stage 3 成熟；
- 仙品 / 神品在顶点色上做“玉白微光 / 金黄”，不破坏原型。

### P5 草药特效（需求 8 核心）
- `cropAuras.ts` 增加 7 个配方：五行各自配色 + 运动（金=细碎金尘上浮、木=叶影光点、水=水波雾、火=火星、土=尘雾）；
- 仙品：3 层不同尺度云絮缓慢环绕 + 植株范围闪烁光点（正弦相位错开）+ 柔光晕；
- 神品：程序化 Canvas 分形闪电贴图（每次随机种子重绘）+ additive sprite 随机闪现 + 整株金黄光晕 + 地面电弧；
- 全部使用贴图 / 粒子 / shader，禁止几何拼凑；发光点数量按地块数上限控制。

### P6 验收与发布
1. 容器内 `npx tsc --noEmit` + `npx vite build`；
2. `npx tsx scripts/check-forage-anchors.mts`；
3. 后端 `blog_front` 编译检查（`@farm-rules` 共享）；
4. 浏览器实测（5174）：种子排序、两行提示、好友农场动作/坐骑、发言气泡、踢人、移动端菜单、牧场售卖、草药种植/采摘/图鉴/特效截图；
5. `sync-to-site` → README 开发记录 → commit → push（HTTPS_PROXY）。

## 4. 验收标准（逐条可测）

### 需求 1 · 种子排序
- [ ] 种子数 >0 且已解锁的作物排在最前，按数量严格降序。
- [ ] 种子数 =0 的已解锁作物排在中间，未解锁作物排在最后。
- [ ] 数量相同时顺序稳定（按解锁等级、再按 id），刷新页面不变。
- [ ] 野菜 / 草药种子只有捡到过才出现，且遵守同一排序规则。

### 需求 2 · 操作提示
- [ ] 任意时刻屏幕上最多 2 条提示；第 3 条到来时最旧一条立即退场。
- [ ] 单条提示最多显示两行，超出用省略号，不撑高、不遮种子栏。
- [ ] 新提示有轻微上浮 + 淡入，旧提示淡出，不闪烁。

### 需求 3 · 好友农场动作 / 坐骑
- [ ] 好友农场 HUD 有“动作”入口，7 个动作都能播放，且同场玩家能看到动作。
- [ ] 坐骑按钮始终可见：有可骑动物即可召唤；未设坐骑时自动选第一只。
- [ ] 召唤后本地坐骑模型出现、角色坐上、移速生效；点“下坐骑”恢复步行。
- [ ] 无可用坐骑时按钮禁用并提示“牧场还没有可骑的动物”。

### 需求 4 · 发言
- [ ] 主层有“发言”按钮，点击弹出面板：上方是房间消息历史（最近 20 条），下方输入框。
- [ ] 发送后本地人物头顶出现气泡，持续 30 秒后消失；连续发言替换为最新一条。
- [ ] 同房间其他玩家 2 秒内看到气泡；历史记录刷新后仍在（DB 持久化）。
- [ ] 空消息 / 超过 80 字 / 1 秒内重复发送被拦截并提示。

### 需求 5 · 踢人
- [ ] 房主在自己农场能看到“在场访客”列表，每人有“请离”按钮。
- [ ] 点击后访客 2 秒内回到自己农场，并看到“你已被房主请离”提示。
- [ ] 被踢访客 5 分钟内重进该农场被拒绝；好友关系不受影响。
- [ ] 非房主看不到请离按钮，直接调用接口返回 403。

### 需求 6 · 移动端菜单
- [ ] 375px 宽度下主层只有：人物信息、金币、农场、牧场、菜单，共 5 个触控区，互不重叠。
- [ ] 菜单展开后可见图鉴、排行、商店、好友、动作、天气、操作说明、返回登录。
- [ ] 所有按钮触控高度 ≥ 40px；菜单不遮挡虚拟摇杆和种子栏。

### 需求 7 · 牧场售卖
- [ ] 每只动物显示售价；点击售卖弹二次确认。
- [ ] 确认后金币增加、动物移除、容量释放；卖出的是当前坐骑则自动下马。
- [ ] 刷新后状态与后端一致（存档含金币与牧场）。

### 需求 8 · 草药
- [ ] 50 种草药全部能在图鉴“草药”页查看（名称、文案、售价、生长时间、变异倍率）。
- [ ] 种下草药能正常生长、成熟、收获、卖出；存档刷新不丢失。
- [ ] 野外 28 丛中约 40% 为草药；采摘有约 45% 概率掉落对应种子。
- [ ] 播种可抽出五行（金木水火土）、仙品、神品；倍率分别为 4/4/4/5/5、15、30。
- [ ] 仙品：多层云雾环绕 + 植株闪光；神品：分形闪电随机闪现 + 作物整体发黄。
- [ ] 特效为贴图 / 粒子 / shader，无几何拼凑；1660 级别显卡下 4 块地同时仙品/神品不掉帧（≥50fps）。
- [ ] 后端 `normalizeSave` 不裁剪草药种子与收成，好友串门能看到草药。

## 5. 风险与对策

| 风险 | 对策 |
|------|------|
| `crops.ts` / `ranch.ts` 被后端共享，改类型可能连带编译失败 | 每阶段先在容器里跑前端 tsc + 后端 tsc |
| 存档白名单裁剪新作物 | 改完立刻用测试账号 PUT/GET 往返验证 |
| 50 种 × 4 地块 × 粒子导致掉帧 | 发光点按地块上限、低阶段减量、同屏只保留近处特效 |
| 移动端菜单与摇杆 / 种子栏冲突 | 用 `env(safe-area-inset-bottom)` + 媒体查询，375px 实测 |
| 聊天轮询增加请求量 | 1.6s 间隔、页面隐藏时暂停、只拉增量 |
