# 第二十四轮：野外刷新机制重构（野菜批次 + 持久草药 + 菌季封顶）

日期：2026-11-25
范围：只改野外作物的刷新/采摘规则与展示文案，不改价格、金币收入与经验公式数值。

## 一、本轮确定的规则

### 1. 野菜（20 种）

| 项目 | 规则 |
| --- | --- |
| 刷新节奏 | 每 10 分钟整批刷新一次 |
| 每批数量 | 10 株，品种随机 |
| 落点 | 30 个野外锚点中随机取 10 个，只在草地；不进城镇、售货大厅停车场、院子、牧场保留区、河谷、桥面、土路、野兽空地 |
| 变异 | 20%，阴阳 / 长生随机（级别沿用 1/2/3 与原权重） |
| 掉种子 | 35% |
| 上一批剩余 | 换轮直接作废，不累积到下一批 |
| 采摘记录 | 按轮次存 `taken: number[]`（slot），同一轮内重进看到同一批 |

### 2. 草药（50 种，常见 20 / 中档 19 / 珍稀 11）

| 项目 | 规则 |
| --- | --- |
| 刷新节奏 | 每 5 分钟长出 1 株，落点随机（15 个草药槽位） |
| 存在上限 | 地面最多 15 株；超出时随机清掉 1 株 |
| 是否消失 | 不被采摘就一直保留，整份列表随存档保存 |
| 档位概率 | 常见 70% / 中档 20% / 珍稀 10%（档内品种随机） |
| 基础掉种子 | 常见 35% / 中档 20% / 珍稀 10% |
| 五行变异 | 20%（金 / 木 / 水 / 火 / 土随机），掉种子 5% |
| 特殊变异 | 10%（仙品 / 神品各半），掉种子 3% |
| 无变异 | 70% |

变异一次抽出：先判 20% 五行、再判 10% 仙品/神品，二者互斥，所以"五行 20%""特殊 10%"都精确成立，而不是把特殊算进五行后压到 18%。

### 3. 蘑菇

| 项目 | 规则 |
| --- | --- |
| 刷新条件 | 雨后刷新；雨天转雪不刷 |
| 每场上限 | 30 朵（品种随机，宿主按季节种子洗牌后依次长） |
| 变异 | 20%，魔气 / 氤氲 / 通灵随机 |
| 经济 | 不变 |

## 二、实现要点

- `game/forage.ts`：`WildPatch` 增加 `source: "wild" | "herb"`；`ForageState` 增加 `herbSeed / herbTick / herbCount / herbs[]`。
- 野菜：`wildPatchesAt(now)` 按轮次种子确定性生成 10 个 slot 与品种、变异；换轮整批重抽。
- 草药：`advanceForage(state, now)` 按 5 分钟刻度补齐（最多补 24 小时 / 288 刻），每株用 `herbSeed ^ seq*0x9e3779b1` 的 mulberry32 抽档位、品种、变异与空槽；到 15 株先随机 splice 再 push。
- 掉种：新增 `forageSeedChance(patch)` 统一口径，蔬菜 35%，草药按档位 / 变异状态。
- 锚点：`scene/forageAnchors.ts` 目标 30 个（0–14 野菜、15–29 草药），`looseOk` 也排除停车场，实测长度恰为 30。
- 场景：`scene/forageScene.ts` 合并 `wildPatchesAt` 与 `forage.herbs` 渲染，野菜按 `taken` 隐藏。
- 存档：客户端 `pickSave`、服务端 `normalizeSave`、`ttfarm-visit.ts` 均已适配；旧存档只有 `rotation/taken` 时补默认，草药从当前刻度开始长。
- 服务端协作：访客进入时 `guestState` 先把草药补到当前时刻；代采时同样先 `advanceForage` 再校验这株是否还在。
- 文案：`ui/FarmPanel`、`ui/ForageHUD`、`ui/FieldControls` 改成新规则；README 野菜/草药章节与浇水说明同步。
- 测试：新增 `src/game/forage.test.ts`、`src/scene/forageAnchors.test.ts`。

## 四、本轮不动的部分

- 野菜 / 草药价格与金币产出：未改。
- 经验数值：野菜 4、草药 6，沿用原值。
- 生长时间：野菜仍为 85–150 秒、草药 135–340 秒；"野菜 ≤2 小时、草药 ≤24 小时"的时间表尚未落地，等价格/经验一起改。

## 五、待确认

1. "变异种子"目前是"变异草药按 5% / 3% 掉普通种子"，不是保真变异种子；种子播种仍重新抽变异。若要做真·变异种子，需要改种子键、背包与播种，属于经济/系统改动。
2. 野菜 10 株 / 10 分钟 + 草药 15 株常驻，长期在线时采集收益仍高于种植；若后续价格按 ×10 / ×200–400 落地，建议同步下调密度或给采摘产物折价。
3. 草药上限 15 与"每 5 分钟 1 株"意味着满仓后每小时净换 12 株，长期在线玩家会看到频繁换株，实机需观察是否显得"草药在消失"。
