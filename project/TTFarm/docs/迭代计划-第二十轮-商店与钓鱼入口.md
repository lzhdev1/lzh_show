# 第二十轮：商店与钓鱼入口改版

日期：2026-11-23

## 目标

1. 商店改成与背包一致的页签格子样式，分种子、装备、道具、杂物四类。
2. 钓鱼必须先在背包装备鱼竿，去掉钓鱼按钮旁的换竿按钮。
3. 增加鱼饵选择，无饵可抛竿但不咬钩，咬钩消耗鱼饵。
4. 发言后顶部出现白底黑字「昵称：内容」提示，头顶气泡更清楚。

## 商店

商店复用背包的 `bag-modal / bag-tabs / bag-body / bag-pager / bag-wallet` 结构，新增 `shop.css` 的 4 列商品卡；手机 2 列，每页 12 / 8 件。

- **种子**：直接使用 `SHOP_CROPS`，只含 24 种常规作物，野菜与草药不进入商店。
- **装备**：展示 4 根鱼竿。未购买显示价格与等级锁；已购买提示去背包「装备」页装备；当前竿标「装备中」。卡面与背包格统一使用 `RodGlyph` 竹节竿小图，不再用通用盾牌图标。
- **道具**：12 档成长加速卡，2 / 5 / 10 / 20 / 30 / 40 / 50 / 60 / 120 / 180 / 240 / 300 分钟，单价 18–1420 金币。
- **杂物**：8 种鱼饵，分别为蚯蚓饵、甜玉米饵、麦香饵、红虫饵、小河虾、夜光拟饵、龙涎香饵、万能饵。每种带主诱鱼种和稀有度权重。

鱼竿价格为溪竹竿 0、青锋溪流竿 900、灵纹鲤竿 4200、沧海玄竿 12000。购买鱼竿不会自动装备。

## 背包

- 装备页读取 `ownedRods`，点击格子直接装备；装好的竿显示「装备中」。
- 道具页读取 12 档加速卡库存，点击后在已选地块或最早生长中的地块上使用，按剩余时间截断。
- 杂物页把鱼饵排在蔬菜收成前，点击鱼饵即可选中或取消；鱼饵与蔬菜共用杂物容量。
- 容量校验同步覆盖购买鱼饵、收获作物、购买加速卡和购买鱼竿。

## 钓鱼

- `FishingDock` 未装备鱼竿时返回 `null`，钓鱼按钮不再常驻；`FishingGearPanel` 与顶部「钓具」菜单入口一并下线。
- 钓鱼主按钮左侧新增 52px 鱼饵按钮，点开可查看 8 种鱼饵库存和目标鱼种，也可选择「不用鱼饵」。
- 抛竿时锁定本次鱼饵：选中饵且库存大于 0 才挂饵；没饵或选空钩仍可抛竿。
- 浮漂等待结束后检查鱼饵库存：空钩直接进入空钩结果，不产生咬钩；有饵则消耗一枚，并按鱼饵的稀有度权重调用 `rollFish(random, weights)`。
- 默认新号带 3 条蚯蚓饵；旧号通过 `shop_extras` 默认值补齐。

## 发言

- `sendChat()` 成功后主动调用 `notify("昵称：内容", "chat", 9000)`，并把自己消息写入 `seen`，避免轮询重复提示。
- 顶部 `.toast.chat` 继续使用白底、黑字、左对齐、600 字重。
- 头顶气泡 Canvas 从 512×256 提升到 1024×520，字体改为 600 58px，行高 74，最多 5 行；圆角、外描边、内高光、落影和尾巴重绘，纹理各向异性升到 8。世界宽度从 2.15 提到 3.2，短句气泡盒最小 360 画布像素，避免六个字缩成小胶囊；实测“提示立即检查”字高约 15px，边缘和笔画清楚。

## 存档

- 客户端 `GameData` 新增 `items / materials / ownedRods / selectedBait`。
- 服务端新增单列 `farm_states.shop_extras`，存 `{ items, materials, ownedRods, selectedBait }`，`save_version` 升到 8。
- 客户端草稿、账号恢复、自动保存字段比较、多端合并均接入库存；物品/鱼饵按增量合并，鱼竿取并集，加速卡与鱼饵不足时判定冲突。
- `Dockerfile` 的 `farm-rules` COPY 列表加入 `items.ts`。

## 验证

- TTFarm `pnpm typecheck`、`pnpm build` 通过。
- 主站 `pnpm exec tsc --noEmit` 通过。
- 本地浏览器验收：商店四页签与商品卡、购买蚯蚓饵、背包装备页点击换竿、杂物页鱼饵选择、发言顶部白底提示、头顶气泡显示正常。
- 本地生产版复验：购买青锋溪流竿后提示「去背包「装备」页装备」，背包装备页出现该竿并成功装备，右下角竿名同步为青锋溪流竿；鱼饵弹层显示「不用鱼饵」与 8 种鱼饵库存，选空钩后 HUD 显示「空钩」。
- 本地数据库确认 `shop_extras` 写入与回读，`save_version=8`；实测库存已含新买的 `stream` 与 `boost-2`。
