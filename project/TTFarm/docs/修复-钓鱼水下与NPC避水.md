# 钓鱼体验修复：河鱼下潜、QTE 降速、NPC 避水

## 问题

1. 河鱼全部贴着水面上浮，背脊露出水面，像在“水面上游”。
2. 拉鱼 QTE 的小球过快，高亮区又窄，正常点击几乎抓不住时机。
3. 行人、访客或野生动物会踩进河面，出现水上行走。

## 修复

### 河鱼真正下潜

- `riverFish.ts` 新增 `swimDepth()`：按鱼体高度计算中心深度，鱼背、背鳍最高点都压在水面以下。
- 鱼体中心深度 = `体高 × 体长缩放 + 0.055~0.115m`，大鱼按体型自动加深，不会再穿出水面。
- 保留很小的上下游动起伏，并增加轻微俯仰；不再用“鱼背出水”补可见性。
- 每条鱼在水面增加一层低透明度鱼影，鱼本体完全在水下，但仍能看出鱼群位置和游动方向。
- 鱼影只在 72m 内显示，鱼体 110m 外隐藏，避免远处水面出现碎点。

### 拉鱼 QTE 降速

- 高亮区基础宽度放宽：常见 0.33、少见 0.26、稀有 0.20、史诗 0.155、传说 0.115。
- 同稀有度内仍按价格收窄，最多收窄 16%，再叠加鱼竿加成，限制在 0.078~0.40。
- 小球基础速度整体降低：常见 0.24、少见 0.27、稀有 0.30、史诗 0.34、传说 0.38，同档高价鱼最多再加 18%。
- 保留了“越贵越窄、球越快”的梯度，但传说鱼在高亮区内的可点击时间从约 0.04 秒提升到约 0.28 秒。

### NPC 不再踩水

- 城内行人：选择下一个路点时过滤水面节点与跨水线段；行走过程中一旦下一步落进河面且不在桥上，就退回当前岸上节点。
- 过桥顾客：路线点先做避水校正；若插值点落入河面，会拉回桥面中轴，不再沿水面前进。
- 野生动物：椭圆漫游目标接近水面时，沿河道法线推回岸边，不会走进河里。
- 访客：落点已经在河面且不在桥上时，强制切换游泳姿态，不再保持走路动作。
