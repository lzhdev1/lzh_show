# 修复：好友农场可以驾驶自己的车

## 需求

在好友农场串门时，也能开自己的车。

## 原因

好友农场的驾驶入口本身已经显示，车辆读取的也是自己的车库；问题在场景代码：`startDriving` 发现处于任何 `visit` 状态都会直接提示「做客时不能开自己的车」，并清掉驾驶请求。

同时，好友界面已经有自己的坐骑召唤逻辑，说明“带自己的移动方式去串门”本身是既有方向；车辆只是被单独拦掉了。

## 实现

只调整 `src/game/loop.ts` 的上车入口：

- 好友串门 `visit.mode === "friend"`：允许使用自己的车。
- 排行榜参观 `visit.mode === "spectate"`：继续禁止驾驶，提示「参观模式不能驾驶，回到自己的农场再上车」。参观模式使用自由镜头，不运行访客角色控制，开车会与镜头模式冲突。
- 在访客状态上车时，同步把 `visitOnFoot` 置为 `true`，与坐骑互斥；避免之前骑着坐骑、又切到车辆时，访客 HUD 还停留在“下坐骑”状态。
- 车辆沿用玩家自己的 `garage.cars`、`activeId`、车牌与配色，不读取好友车库。
- 离开好友农场或进入另一个房间时，仍按原逻辑结束驾驶，避免车辆跨房间残留。
- 车辆碰撞、地形高度、桥梁高度、第三人称镜头、桌面与手机驾驶按键全部复用现有驾驶链路。

## 验收

- 开发环境临时建立好友关系，并给测试账号放入一台「赤陶」：
  - 进入好友「动作同步测试」的农场，右上角显示「驾驶」入口。
  - 展开「我的车辆」能看到自己的赤陶 `京A·T01`。
  - 点击「驾驶」成功上车，提示「已上车：京A·T01」，镜头切到车辆，按钮变为「结束驾驶」。
  - 按 W 可以正常前进，车辆在好友农田与牧场之间行驶。
  - 点击「结束驾驶」回到人物视角，访客 HUD 恢复「召唤野马」与「驾驶」入口。
- 排行榜参观模式保持禁止驾驶。
- `pnpm typecheck`、`pnpm build` 通过。
- 测试用的好友关系与测试车辆已删除，测试账号恢复金币 1031、车库为空、收集记录 33 条。
