# 第二十六轮：野菜、草药与蘑菇经济

> 目标：把野外三类作物接进新经济体系：单价按品质递进、采摘份数、种子概率统一，并把野菜 / 草药种回地里的生长时长重排。蘑菇只做采摘价值，暂不开放种植。

## 一、野菜（20 种）

- 单价：60 → 500 金币/份，20 档递进（60 / 75 / 90 / ... / 450 / 500），档位按原售价排序后重排。
- 采摘份数：1–4 份随机。
- 生长：种回地里 3 分钟 → 1 小时，每档 +3 分钟（180s、360s …… 3,600s）。
- 变异不变：野外 20% 自带阴阳 / 长生；售价 ×4 / ×8 / ×16（阴阳）、×5 / ×10 / ×20（长生）。
- 种植抽签：10% 变异，对齐普通作物精灵变异的概率；阴阳 / 长生各半，级别 68% / 25% / 7%。

## 二、草药（50 种）

- 单价：600 → 25,800 金币/份，按三档品质分带：
  - 常见 20 种：600 起，每档 +70，最高 1,930
  - 中档 19 种：2,200 起，每档 +330，最高 8,140
  - 珍稀 11 种：9,000 起，每档 +1,680，最高 25,800
- 采摘份数：固定 1 份。
- 生长：1 小时 → 36 小时，按全表品质均匀递进（四舍五入到分钟）。
- 变异不变：野外五行 20%（金木水火土随机）、仙品或神品 10%；售价 ×4 / ×5（五行）、×15（仙品）、×30（神品）。
- 种植抽签：五行 20%（视作普通变异），仙品 / 神品合计 10%（各半，对齐精灵变异概率）。

## 三、蘑菇（100 种）

- 单价按稀有度：常见 30、少见 120、稀有 480、珍稀 1,920、传说 6,666 金币/份。
- 采摘份数：1–3 份随机，采下直接折算金币（菌类不进仓库）。
- 刷新与变异不变：雨后一场最多 30 朵，20% 变异（魔气 / 氤氲 / 通灵）；菌类变异目前只改外观，不参与售价倍率。
- 普通地块不能种，种植与种子系统本轮不接。

## 四、种子概率

- 普通种子：野菜 / 草药 / 蘑菇统一 **30%**（蘑菇暂不产种子，因为不能种）。
- 变异种子：采到带变异的野菜 / 草药时，在普通种子之外**额外**按 **20%** 掉一颗变异种子，键为 `作物:变异`，可直接播种并保证带该变异。
- 服务端协作采摘同步：份数、普通种子、变异种子都按同一套规则结算。

## 五、落点

- `src/game/crops.ts`：野菜 / 草药单价与生长重排、`forageYieldOf`、`harvestYieldOf` 支持野菜 1–4。
- `src/game/mushrooms.ts`：`MUSHROOM_RARITY_PRICE`、`mushroomYieldOf`。
- `src/game/forage.ts`：种子概率统一 30% / 变异种子 20%。
- `src/game/forageActions.ts`：采摘份数、变异种子入库。
- `src/game/state.ts`：蘑菇 1–3 份折算金币。
- `src/game/weather.ts`：野菜 10%、草药五行 20% / 特殊 10% 的种植抽签。
- UI：`FarmPanel`、`ForageHUD`、`CodexPanel`、`MushroomHUD` 文案。
- 服务端 `blog_front/src/lib/ttfarm-visit.ts`：协作采摘与采菌同步。
- 测试：`economy.test.ts` 扩到 12 项，`forage.test.ts` 更新种子概率断言。
