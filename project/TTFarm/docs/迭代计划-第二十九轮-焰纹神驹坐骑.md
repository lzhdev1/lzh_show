# 第二十九轮：焰纹神驹与专属坐骑

## 目标

把 `A_test/fire-horse` 验证成型的火焰马落进正式游戏 `project/TTFarm`：作为野外可收服的稀有马匹，入住坐骑栏后可骑乘，骑乘速度与野马同为 3 倍。

## 实施

| 模块 | 改动 |
| --- | --- |
| `src/game/ranch.ts` | 新增 `flameHorse` 物种「焰纹神驹」；抽出 `HORSE_SPECIES` / `isHorseSpecies`，野马与神驹都无需五行变异即可骑；每轮野外刷新固定留一个神驹 slot。 |
| `src/scene/flameHorseFx.ts` | 新增神驹专属外观：马体黑曜石底 + 呼吸熔岩裂纹自发光；鬃尾按本地 Y 轴做根暗梢亮的火焰渐变；同几何加色火壳做边缘侵蚀；**7 层交叉切片组成的体积火锚在鬃尾真实顶点上**，尾部向下烧、鬃部向上烧，并固定按“头→脊椎”的反向（马尾方向）做三维风剪切，奔跑时火焰始终向马尾一侧后掠；臀部余烬、蹄下光斑与一盏跟随暖光。 |

## 收服与骑乘链路

1. 每 12 分钟一轮的野外刷新中，`flameHorse` 固定占 slot 0，保证每一轮都能遇到。
2. 靠近后投喂萝卜收服；收服对象写入 `ranch.animals`，`isMountAnimal` 判定为真。
3. 牧场达到 3 级后进入坐骑栏；牧场面板或顶部坐骑按钮均可选择骑乘。
4. 骑乘时速度倍率为 `HORSE_SPEED_FACTOR = 3`；下水自动下坐骑等既有规则不变。
