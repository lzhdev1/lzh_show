# 第十六轮：坐骑置顶

基线：第十五轮 `47018bf`。本轮只给坐骑栏加用户自选的置顶排序，不改骑乘、出售、出栏和放归。

## 1. 存档字段

- `RanchState` 新增 `pinnedMounts: string[]`，顺序就是置顶顺序。
- `normalizeRanch` 兼容旧存档：缺省为 `[]`，只保留仍在坐骑栏里的坐骑，自动去重。
- 存档仍存放在原有 `farm_states.ranch` JSON 中，不需要改数据库表。

## 2. 列表排序与操作

- 坐骑栏按 `pinnedMounts` 排序：多个置顶时，新置顶的排最前；未置顶的保持原本顺序。
- 每只坐骑的操作行新增「置顶 / 已置顶」切换按钮，带 `aria-pressed` 和「置顶 / 取消置顶 + 坐骑名」的 `aria-label`。
- 已置顶的坐骑行加暖色底、金色描边和「置顶」小标签；按钮切换为浅金底。
- `toggleMountPin` 写入存档；放归、卖出、出栏时同时移出 `pinnedMounts`，避免留下失效 ID。
- 放牧区不显示置顶按钮，排序也不受影响。

## 3. 验证

- 临时给测试账号写入 5 只坐骑：
  - 坐骑栏显示「置顶」按钮；
  - 置顶星岩·熊猫后排到第一，带「置顶」标签；
  - 再置顶绯焰·灰狼，灰狼排到熊猫前；
  - 刷新页面后顺序仍是灰狼、熊猫，存档里为 `["qa-wolf-fire","qa-panda-earth"]`。
- 测试后已恢复测试账号原始牧场存档（1 级、1 匹野马），未留下临时坐骑。
- 容器内 `pnpm typecheck` 通过。
- 容器内 `pnpm build` 通过（`index-CStUxYwc.js`、`index-Cact2lF-.css`）。
