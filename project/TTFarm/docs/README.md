## 维护约定

- 新功能先写一份 `迭代计划-第N轮-主题.md`，再动代码；修复类文档用 `修复-主题.md`。
- 文档里的文件路径以仓库根目录 `lzh_show` 为基准时，需要写全 `project/TTFarm/...`；只在 `TTFarm` 内部相对引用时可省略前缀。
- 过期的过程截图不放 `docs/`，统一归档到本地缓存目录，文档只保留可复现的结论与链接。
