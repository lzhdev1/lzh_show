# TTFarm 第九轮迭代计划 · 河东小城

> 目标：在桥东侧空地建一座可走进、可看、可绕行的三渲二小城：高楼、平房门店、柏油十字路、随机行人、行驶车辆，以及十字路口一角的双面落地窗汽车店。
> 执行顺序：P0 布局定稿 → P1 三渲二材质 → P2 道路与街区 → P3 建筑与汽车店 → P4 行人车辆 → P5 碰撞/场景接入 → P6 验证与交付。

---

**建筑清单（默认，均可在 `townLayout.ts` 调）**

- 高楼 4 栋：30m（退台 3 段）、22m、36m（奶油+钢蓝）、20m 公寓。
- 中层公寓 3 栋：14~15m，带阳台，填塔楼之间的街区纵深。

## 2. 关键设计

- **三渲二**：`MeshToonMaterial` + 4 阶 `DataTexture` ramp；所有静态结构按“实心 / 玻璃”两类 merge 成少量网格，顶点色控制配色。建筑、汽车、行人加反壳描边（法线外扩 BackSide），描边宽 0.03m（近景建筑 0.05m）。拒绝贴照片纹理，靠形体与色块。
- **路面**：贴地 0.02m 的深灰柏油板；路缘石高 0.14m；人行道铺 0.12m 高的浅米色板；车道虚线、斑马线用 merge 几何，避免 z-fighting。
- **汽车店**：玻璃用半透明 `MeshStandardMaterial`（opacity 0.28），内侧可见两辆展车与圆形展台；白色竖梃分格但保留“超大整面”的观感，招牌用 CanvasTexture 中文。
- **行人**：每名 NPC 3 个网格（身体 merge + 左右腿），共用 toon 材质；沿人行道节点图随机选下一节点，过街只走斑马线；到店门口有 20% 概率停留 1.5~3.5s。
- **车辆**：6 辆车整车 merge（车身/车窗/轮胎顶点色），沿两条路的四条车道匀速循环；到路口按信号灯相位减速停车（简化：路口 8m 内遇红灯缓停，绿灯起步），不做转向。
- **碰撞**：建筑、路灯、花坛、信号灯、汽车店展台加 `WorldObstacles`；行人/车不加碰撞，避免卡住玩家。
- **场景排除**：`world.ts` 的树 / 石 / 草丛散布在城镇矩形内全部跳过，防止穿模；城镇铺面上另铺人行道与花坛。
- **不改存档协议**：小城是纯场景内容，无新字段、无接口改动。

## 4. 验收标准（逐条可测）

1. **可达性**：从农场过桥向东，脚下连续为道路/人行道，无河面缺口；返程畅通。
2. **路网**：两条 ≥7m 宽柏油路正交成十字，含车道虚线、四条斑马线、连续路缘与两侧人行道；路面不压河、不悬空。
3. **高楼**：≥3 栋高度 ≥20m 的塔楼，具备窗带、退台或屋顶构件；近景可见明确三渲二明暗阶。
4. **门店**：≥8 家平房门店沿街布置，均有招牌（中文可读）、雨棚/门头、玻璃门；招牌不重叠、不悬空。
5. **汽车店**：位于十字路口一角（主大道北侧、十字街西侧）；北面、东面各有一块 ≥8m×6m 的整面落地玻璃，分别正对主大道与十字街；玻璃内可见 ≥2 台展车；店招「星野汽车」清晰。
6. **行人**：≥12 名 NPC 持续行走，路线只落在人行道与斑马线；不穿建筑、不入河、不长时间静止；有步态（腿摆动 + 上下起伏）。
7. **车辆**：≥6 台车在四条车道循环行驶，车身/车窗/轮胎分色，路口遇红灯会减速；不叠在建筑或人行道上。
8. **碰撞**：高楼、门店、汽车店、路灯、花坛、信号灯不可穿过；桥头到店门口的步行路线可走通。
9. **场景整洁**：城镇矩形内无树木/石头与建筑穿插；远处山脊线、农场围栏不受影响。
10. **性能与工程**：城镇新增 draw call 在地面常态 ≤ 220（实测路口相机 188；高空俯瞰全场景 366），浏览器实测无明显掉帧；`npx tsc --noEmit` 前后端通过；`npx vite build` 通过；`sync-to-site` 成功；README 追加第九轮记录；提交到 main。

## 5. 风险与对策

| 风险 | 对策 |
|------|------|
| 建筑过多导致 draw call 飙升 | 每栋建筑 merge 为 1~2 个网格；装饰按类型合并；行人 3 网格/人、车 1 网格/台 |
| 描边壳在远处过粗 | 描边宽度按体量分档（高楼 0.05、门店 0.035、车 0.02） |
| 树石穿模 | `world.ts` 散布前统一 `inTown()` 排除 |
| 阴影相机只覆盖人物周围 | 静态建筑 `castShadow=true`，靠近时由现有跟随阴影照亮即可 |
| 车辆与行人重叠 | 车只在车道、人只在人行道，斑马线为唯一交汇；信号灯相位错开 |
| 招牌文字发糊 | Canvas 512×128、粗体、留 12% 边距，贴图 `anisotropy=4` |
