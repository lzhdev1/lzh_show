# 第二十五轮：普通作物经济与变异规则

> 目标：把普通作物从「测试期随便定价」改成可长期运行的经济骨架，同时把变异从「播种即定」改成「生长阶段逐段判定」。
> 范围：只动普通作物与变异规则；野外采集、蘑菇、钓鱼、牧场价格本轮不动。经验与等级留到下一轮单独定。

## 一、定价

新号开局 **5,000 金币**（客户端 `TEST_COINS`、服务端 `START_COINS` 同步）。

24 种普通作物按解锁等级分 12 档，同档两种作物同价：

| 等级 | 作物 | 单份售价 | 种子价（×0.6） | 满收 5 份 |
|---|---|---|---|---|
| L1 | 萝卜、白菜 | 60 | 36 | 300 |
| L2 | 茄子、番茄 | 78 | 47 | 390 |
| L3 | 豆角、玉米 | 98 | 59 | 490 |
| L4 | 辣椒、草莓 | 126 | 76 | 630 |
| L5 | 西瓜、南瓜 | 160 | 96 | 800 |
| L6 | 桃子、梨 | 205 | 123 | 1,025 |
| L7 | 杏、枣 | 262 | 157 | 1,310 |
| L8 | 郁金香、百合 | 335 | 201 | 1,675 |
| L9 | 红玫瑰、粉玫瑰 | 430 | 258 | 2,150 |
| L10 | 白玫瑰、黄玫瑰、蓝玫瑰、紫玫瑰 | 550 | 330 | 2,750 |
| L11 | 菠萝 | 700 | 420 | 3,500 |
| L12 | 榴莲 | 900 | 540 | 4,500 |

- 种子价 = 单份售价 × 60%，四舍五入。
- 每块地成熟收获 **1–5 份随机**（均值 3）。份数由 `harvestYieldOf(crop, plotId, plantedAt)` 确定性哈希得出，刷新、跨设备、好友代收结果一致。
- 变异倍数沿用现有规则：雷霆 / 冰霜 / 神火 ×2、黄金 ×3、大地 / 风 ×5、精灵 ×8。

### 时薪取舍（已确认）

生长时长没改，价格只涨约 15 倍，而 L1 三分钟到 L12 十八小时是 360 倍差距，因此在线时薪从约 2,600 / 时降到 110 / 时。用户选择方案 A：接受「低级在线快、高级当离线作物」，不再为长周期作物额外加价。

## 二、变异规则

旧规则：播种瞬间 `rollMutation(weather)` 定生死，界面立刻能看出变异。

新规则：

1. 普通种子播种时 `mutation = null`，只写入本茬的 `plantSeed`（随机 uint）与 `mutationChecked = 0`。
2. 生长分三段：发芽 18%、成长 50%、成熟 100%。进入每个阶段时各判一次变异，概率 `1-(1-天气总概率)^(1/3)`，整茬合计仍等于天气面板显示的概率（晴天约 8%、雷雨约 20%）。
3. 一旦命中就锁定变异种类，`mutationChecked` 直接记 3，后续阶段不再改。
4. 成熟阶段命中时 30% 抽精灵、70% 抽元素；发芽与成长阶段只出元素。
5. 判定用 `plantSeed` + 阶段做确定性随机，离线跨阶段、换设备重算结果一致。
6. 界面在 `cropStage < 1` 时一律按普通作物显示（菜地动作卡、访客 HUD、3D 模型与光效）；发芽后才显形。

## 三、变异种子

- 商店不出售。收获带变异的作物时 **30%** 概率额外掉一颗同变异种子，键为 `作物:变异`（如 `radish:gold`）。
- 变异种子播种时直接带该变异、`mutationChecked = 3`，但界面同样从发芽阶段才显示。
- 客户端 `seeds` 与 `selectedSeed` 从 `CropId` 扩为字符串键；`SEED_KEYS` 覆盖全部合法组合。
- 服务端存档白名单同步接受 `id:mutation` 键，`selected_seed` 校验同步放宽。
- 背包种子页、撒种栏单列变异种子；撒种按钮用紫色渐变（`.seed.variant`）区分。

## 四、落点清单

客户端（`project/TTFarm`）：

- `src/game/crops.ts`：24 种价格 / 种子价、`harvestYieldOf`、`MUTATION_SEED_DROP_CHANCE`、`seedKey` / `parseSeedKey` / `seedInfoOf`。
- `src/game/growth.ts`：`plantSeed` / `mutationChecked` 字段、`stageMutationChance`、`settlePlotMutation`、`plotMutationRevealed`。
- `src/game/state.ts`：开局 5000、字符串种子键、`settleMutations`、播种 / 收获重写、变异种子掉落。
- `src/runtime/loop.ts`：每 500ms 结算阶段变异。
- UI：`App.tsx`（变异种子按钮）、`PlotAction.tsx`、`VisitHUD.tsx`、`BackpackPanel.tsx`、`CodexPanel.tsx`、`scene/plots.ts`、`styles.css`。
- 测试：`src/game/economy.test.ts`（价格递进、种子 0.6、份数 1–5、变异种子、阶段锁定）。

服务端（`blog_front`）：

- `src/lib/ttfarm-save.ts`：`START_COINS = 5000`、`SEED_KEYS` 白名单、地块新字段归一化、`selectedSeed` 校验。
- `src/lib/ttfarm-visit.ts`：协作播种支持变异种子且播种不再判变异；协作收获先结算阶段变异、按 `harvestYieldOf` 给份数、30% 掉变异种子。
