# 第十三轮：手机端驾驶改成左右按键

基线：第十二轮 `5716ba5`。本轮只改手机驾驶输入，不动车内模型与行驶手感。

## 1. 原来的问题

手机端上下车沿用步行那一套左下摇杆：摇杆的 `x / forward` 直接喂给 `loop.ts` 的车辆输入。驾驶时仍是一个圆摇杆，方向盘和油门混在一个轴上，手机上不好同时控制油门与转向。

## 2. 新布局

新增 `DriveTouchControls`（`ui/FieldControls.tsx`），只在 `useDrive.driving` 为真时替换普通 `TouchControls`：

- 左侧竖向两个大按键：`前进` / `后退`，对应 `farmInput.forward = +1 / -1`。
- 右侧横向两个大按键：`左转` / `右转`，对应 `farmInput.x = -1 / +1`。
- 每次按下用 Pointer Capture 锁住手指，支持左右手同时按住；松开、取消、失焦、页面隐藏或组件卸载都会清零，避免按键卡住。
- 桌面端不显示按键，W/S、A/D、空格、Shift 键盘驾驶保持不变。

样式在 `ui/drive.css`：

- 默认 `display: none`，只在 `.hud[data-input="touch"]` 下显示。
- 竖向 / 横向两组均避开底部种子栏，`bottom: calc(84px + safe-area)`。
- 按钮 68×68，圆角 24，软阴影 + 暖金箭头；按下有内阴影、下沉和金色描边。
- 横屏低高度（`any-pointer: coarse` + `max-height: 520px`）缩到 58×58，并落到屏幕底角。

驾驶面板提示同步改成两套文案：桌面显示键位，手机显示「左侧前进 / 后退 · 右侧左转 / 右转」；操作说明的手机页也补了这一行。

## 3. 验证

- `npx tsc --noEmit` 通过。
- `npx vite build` 通过（199 modules）。
- `node scripts/sync-to-site.mjs` 同步到 `blog_front/public/ttfarm`。
- 浏览器以触屏样式预览：左下 `前进 / 后退`、右下 `左转 / 右转` 四键位置正常，未压住种子栏、发言与结束驾驶按钮。
