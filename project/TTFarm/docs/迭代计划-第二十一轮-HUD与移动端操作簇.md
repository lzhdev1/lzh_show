# 第二十一轮：HUD 与移动端操作簇

## 目标

本轮不改玩法，只重排页面覆盖层，解决四类操作体验问题：

1. 打开图鉴、背包等弹窗时，驾驶 / 发言按钮不再压住弹窗内容。
2. PC 端所有顶部按钮收进人物头像同一行，右下角钓鱼按钮位置保持不动。
3. 图鉴外框固定高度，切换作物 / 鱼类等页签时不再忽长忽短。
4. 移动端右下角改成传统手游式「大按钮 + 三个小按钮」弧形操作簇，并适配 Android / iOS、不同分辨率与横竖屏；顶部头像行和底部种子栏始终各留 2px 贴边。

## 弹窗层级

- `ChatDock` 从页面底部独立 fixed 层移进 `header .top-right`，PC 端驾驶、发言与头像同行。
- `.chat-dock` 改为 `position: relative; z-index: 3`，低于 `.modal-scrim` 的基础 `z-index: 4`，也低于背包 / 图鉴的 `70`。打开任意弹窗后，驾驶 / 发言位于遮罩下方，点击不到，也不会盖住内容。
- 手机端仍把驾驶 / 发言固定在顶部第二行右侧，不跟随 PC 布局。
- 驾驶卡片改为相对 `drive-dock` 绝对定位；手机端改为 `position: fixed`，右侧贴边、顶部 `102px`，不再把 `chat-dock` 撑宽，也不会从屏幕左侧溢出。

## PC 顶栏

顺序固定为：人物资料 → 天气 / 操作说明 / 角色动作 / 农场 / 牧场 / 商店 / 好友 / 返回登录 → 图鉴 / 排行 / 背包 / 驾驶 / 发言 / 菜单。

- `field-status` 从独立 fixed 层移进 `header`，桌面态 `position: static`。
- `821–1359px` 用紧凑图标版：按钮约 40px，隐藏文字只留图标，保证 857px 窄桌面仍是一行；`≥1360px` 恢复文字标签。
- 顶部 `.topbar` 的 `padding-top` 统一为 `2px + safe-area`，人物头像行上边缘距视窗 2px。
- 桌面种子栏宽度改为 `min(760px, calc(100vw - 350px))`，主动给右下角原钓鱼按钮和鱼饵按钮让位；钓鱼控件位置不变，避免贴底后的种子栏压住按钮。

## 图鉴固定高度

`CodexPanel` 把列表、分组标题和说明统一包进 `.codex-body`。`.codex-panel` 固定为：

```css
height: min(720px, calc(100dvh - 44px));
display: flex;
flex-direction: column;
overflow: hidden;
```

标题、页签、进度、搜索工具 `flex: none`，`.codex-body` 使用 `flex: 1; min-height: 0; overflow-y: auto`。手机高度为 `calc(100dvh - 24px)`。实测作物页与鱼类页外框高度均为 720px，鱼类内容 7297px 只在内部滚动。

## 移动端操作簇

新增 `MobileControls.tsx` 与 `mobile-controls.css`。容器 190×190，右 12px，底 `72px + safe-area`：

- 大按钮 76×76，位置就是原钓鱼按钮的位置。
- 小按钮 50×50，从大按钮上方沿弧线排到左侧：跳跃 → 冲刺 → 道具 / 鱼饵。
- 装备鱼竿时，大按钮显示钓鱼，逻辑沿用 `cast / lift`，文字按 idle / casting / waiting / bite / reeling / result 切换。
- 未装备鱼竿时，大按钮显示默认动作。默认动作由 `actionStore.preferred` 决定，动作面板选中任意动作后立即更新并持久化到 `localStorage["ttfarm:preferred-action"]`；点击大按钮播放 / 停止该动作。
- 鱼竿可在背包装备页点击装备；点击「装备中」的鱼竿即卸下。卸下后大按钮自动退回默认动作，鱼饵按钮退回「道具」。
- 非钓鱼状态，道具按钮点击使用当前加速卡；长按 480ms 打开加速卡列表。没有生长中的地块时提示且不消耗。
- 钓鱼状态，道具按钮自动变为鱼饵按钮；点击展开鱼饵列表，库存数量降序排列，零库存排后，「不用鱼饵」固定最前。
- 原 `TouchControls` 的独立跳跃按钮、touch 下的 `.fishing-controls` / 竿名隐藏，避免和操作簇重复。
- 跳跃、冲刺、道具按钮都使用 Pointer Events 与 `touch-action: none`，按住冲刺持续奔跑，松开恢复。

## 驾驶键

- `DriveKey` 扩为 `forward | back | left | right | brake`，`farmInput.brake` 进入 `vehicle.update` 刹车参数。
- 手机驾驶时隐藏操作簇与摇杆：左下前进 / 后退，右下上一行左转 / 右转、下一行 144×52 刹车。
- 横屏低高度缩小按键并把两组按键抬到种子栏上方。

## 底部 2px 贴边

- `.dock` 全局 `bottom: calc(2px + env(safe-area-inset-bottom))`。
- 竖屏操作簇底边 `72px`，种子栏高约 61px，两者间隔约 9px。
- 横屏操作簇 `bottom: 80px`，整体缩放 0.86，横屏实测簇底 320、种子栏顶 331，间隔 11px；摇杆底部 78px，不再压住种子栏。
- 顶部头像行实测：360×640、390×720、412×915、720×400、857×775、1720×900 均为 2px 上边距；种子栏均为 2px 下边距。

## 验收记录

- `pnpm typecheck`、`pnpm build` 通过。
- PC 857×775：顶栏单行，图鉴 / 背包打开后驾驶与发言在遮罩之下；种子栏右端 682px，钓鱼控件左端 687px，间隔 5px。
- PC 1720×900：全部按钮同一行，文字标签版，头像上边距 2px，种子栏下边距 2px，钓鱼按钮不重叠。
- 手机 360×640、390×720、412×915：头像行 2px 贴边；种子栏 2px 贴底；操作簇与摇杆、种子栏均不重叠；390 宽下操作簇 188–378、摇杆 18–118，间隔 40px。
- 手机横屏 720×400：操作簇底 320、种子栏顶 331；摇杆底 328、种子栏顶 331；无重叠。
- 图鉴作物 / 鱼类切换：外框高度稳定 720px。
- 卸竿：背包「装备中」角标消失，大按钮从钓鱼变为当前默认动作。
- 选动作：选择「跳舞」后大按钮立即变为「💃跳舞」，刷新仍保留。
- 长按道具：弹出「选择加速卡」；点击使用在无生长地块时提示「没有正在生长的地块，先种一茬再用加速卡」。
- 车库卡片：390×720 下卡片 52–382px，完整显示，不再从左侧裁掉；关闭卡片后操作簇恢复。

## 已知限制

- 本地测试账号车库为空，没有真实车辆，驾驶键只完成代码接线与静态尺寸校验，尚未在车内实按刹车。
- 浏览器自动化 `bu.click()` 产生鼠标事件，会把 `data-input` 切到 desktop；手机交互测试使用 JS 派发 `pointerType: "touch"` 后截图，避免把模拟伪影当成产品问题。
- 360 / 412 / 720×400 为 CDP 视口模拟，不等同 iOS / Android 真机 safe-area；但 2px 贴边使用 `env(safe-area-inset-bottom)`，真机会把 2px 加在安全区之外。
