# 第十二轮：桥上车横向、售货大厅停车场、河对岸空城区

基线：第十一轮 `e5ac1e2`。本轮只处理实机暴露的三项问题，不新增经营玩法。

## 1. 车辆在桥上横着走

`townCar.ts` 的车型约定是局部 `+x` 为车头，但 `townLife.ts` 的两套采样都按 `+z` 车头算：

```ts
// RouteCar.sample()
rotation.y = atan2(tangent.x, tangent.z);
// DeliveryVan.sample()
rotation.y = atan2(tangent.x * forward, tangent.z * forward);
```

两处各差 90°。改为：

```ts
// RouteCar.sample()
rotation.y = atan2(-tangent.z, tangent.x);
// DeliveryVan.sample()
rotation.y = atan2(-tangent.z * forward, tangent.x * forward);
```

玩家车由 `vehicle.ts` 的 `heading` 独立控制，不受影响。
