# 第二十二轮：百种菌季、特殊变异播报与野外刷新

## 目标

本轮一次完成八项体验升级：

1. 鱼咬钩时提竿按钮变色、闪烁并出现「咬钩！」徽章。
2. 手机右下操作簇改为半透明磨砂玻璃，不再是不透明深色按钮。
3. 摇杆只负责方向和常速移动；冲刺改为左下角独立按钮，点一次加速、再点恢复常速。
4. 新增 100 种蘑菇：程序化建模、灌木 / 腐木 / 树干 / 树桩宿主、雨后一个天气阶段出现、进入图鉴。
5. 蘑菇三种变异：魔气、氤氲、通灵。
6. 地图出现非五行普通变异的作物时，顶部弹金黄透明流光条，橙字播报「出现了「xxx」」。
7. 作物和动物不再固定刷在同一点；动物持续随机漫游并避水；收服后的动物放养 / 出栏不再回原收服点。
8. 野外增加土丘与多形状石头，地面不再整片平摊。

## 菌季与百种菌

- `src/game/mushrooms.ts` 内置 100 个中文菌名（赤霞伞、羊肚菌、竹荪、灵芝、猴头菇、毒蝇伞……），id 为 `m001`–`m100`。每种含菌盖 / 菌柄 / 菌褶 / 点缀四色、12 种体态、6 种花纹、宿主、稀有度、价格、尺寸与一句简介；灵芝、竹荪、猴头、毒蝇伞等名种有单独造型覆盖。
- `mushroomSeasonAt(now)`：取当前天气阶段，上一阶段为阵雨 / 雷雨，当前不是雪，菌季才开启；只持续当前一个天气阶段，下一阶段自动收菌。雨后转雪直接取消。
- `mushroomMutationAt(id, seasonKey)`：同一菌在同一天气阶段变异固定，重进不会重 roll。概率为魔气 14%、氤氲 12%、通灵 7%。
- `src/scene/mushroomModels.ts` 程序化建模：菌柄、菌托、菌环、16 片菌褶、12 种菌盖轮廓；疣点、鳞片、环带、发光、珊瑚、马勃、杯形、扇叠、齿盖、胶质等体态。菌褶合并已改为 `toNonIndexed()` 后合并并补 uv，避免带 index 的 BoxGeometry 造成三角面错位。
- `src/scene/wildGarden.ts` 常驻 30 个宿主：倒木、树桩、枯树干、灌木、草坡，间距 ≥ 8.5m，避开农场、牧场、河、桥、路、城、售货大厅和停车场，并注册碰撞。每季每个宿主长 1–3 朵，倒木最多 4 朵；按宿主类型选菌种，同一季尽量不重复。
- 采集：脚边水平距离 2.55m 内出现「菌类采集卡」，显示菌名、稀有度、宿主、价格、变异说明。采后立即从场景撤掉，+菌价金币、+3 XP，并写入图鉴。树干上的菌按脚边水平距离判定，不再因长在 2 米高处而采不到。
- 图鉴新增「菌类」页签：100 张卡片、搜索、只看已收集、收集进度与总数。

## 三种菌类变异

- **魔气**：3 层暗紫色透明球雾包围菌体，雾中 3 个 Canvas 绘制的 Q 版骷髅虚影绕圈；骷髅尺寸与透明度已调高，近看能辨认眼窝、鼻腔和牙。
- **氤氲**：7 条彩色半圆 Torus 叠成小彩虹，4 个极低透明度白雾球包住菌盖。
- **通灵**：不换外观，隔一阵在菌顶弹出吐槽气泡，每 10 秒沿宿主表面挪一步。树干菌只沿树皮小弧移动，朽木菌沿木轴移动，不再飘到半空；气泡放大到默认 3.2m 世界宽度，远处也能读清。

## 特殊变异播报

- `src/game/specialNotice.ts` 判定非普通五行变异（排除 `herbMetal / herbWood / herbWater / herbFire / herbEarth`），播种成功或野外菜丛出生时触发 `ttfarm:special`。
- `SpecialVarietyBanner` 在顶部显示金黄半透明流光条、橙色字与双 ✦，2.1 秒扫光，4.6 秒自动收起；PC 顶边 58px，手机 102px。
- 实测页面加载时真实触发「出现了「阴阳·二星 野菜」」，不是仅靠手动事件。

## 刷新与动物

- 野生菜丛每轮把锚点整体错开 5 位，同一批菜不再永远长在同片草地。
- 野生动物每轮按 7 位偏移换空地（12 个空地，7 与 12 互质，可轮遍全部）。
- 动物删除固定八字循环，改为走到当前随机落点后立刻选下一个落点；牧场动物最小活动半径约 0.36m，野生约 0.82m，持续迈步，不再长期站桩。
- 目标点若距水线不足 1.35m，沿河道法线推回岸上；目标不可走则退回 anchor。
- 收服后放养 / 售卖 / 出栏只从牧场移除，不再生成野生个体；加上每轮换空地，不会回到原收服坐标。

## 地形与石头

- 野外新增 34 个低矮土丘（半径 2.2–7.6、高 0.7–1.95），边缘可走、核心有碰撞，地表出现明显起伏。
- 新增 46 块石头，随机使用十二面体、八面体、二十面体、七棱柱、扁盒、球体 6 种几何，再随机缩放和旋转，形状不再清一色。

## 操作与移动端

- `MobileControls` 的主按钮补上 `phase-${phase}`，咬钩时 `.phase-bite` 真正生效：亮橙红渐变、3px 亮边、亮度和饱和度呼吸、文字变白放大、鱼图标左右摆动，并显示「咬钩！」徽章；PC 钓鱼条同步显示徽章。
- 右下操作簇主按钮和跳跃 / 道具小按钮统一改成 rgba 玻璃 + `backdrop-filter: blur()`，常规态能透出场景。
- 冲刺按钮从右下簇移到左下摇杆右侧，独立圆形玻璃按钮。点击切换 `farmInput.sprint` 与 `running`，按钮文字在「冲刺 / 常速」之间切换，`aria-pressed` 同步；再次点击取消。摇杆幅度不再触发跑步，只负责方向和常速。
- 操作说明同步改为「点左侧冲刺切换加速，再点恢复常速」。

## 已知限制

- 特殊变异播报目前按「排除草药五行」执行，普通作物的雷霆 / 冰霜 / 神火 / 黄金 / 大地 / 风、精灵、阴阳、长生、仙品、神品都会弹条；如果只想播报最稀有档，需要再收窄口径。
- 野外菜丛同一轮刷新若连续出现多个变异，会连续弹多条，尚未合并成队列。
- 收服动物不保存「逐只原收服坐标」，靠换空地和不生成野生个体来避免回到原点。
- 避水只修正漫游目标点，理论上极短的直线路径仍可能擦过浅水边；已通过河道法线外推 1.35m 留出余量。
- CDP 手机截图右侧仍会出现模拟视口白区，页面实际宽度 390，不是产品布局缺失；未在 iOS / Android 真机复核 safe-area。
