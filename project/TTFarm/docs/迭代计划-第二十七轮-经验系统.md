## 二、经验系数

- 锚点：榴莲 18 小时 = 1,080 分钟，收获一次 600 经验。
- 普通作物 / 野菜：`600 / 1080 ≈ 0.5556` 经验/分钟。
- 草药：`0.5556 × 0.5 ≈ 0.2778` 经验/分钟（1 份/次）。
- 蘑菇：每朵固定 **15 经验**（无生长时长，不套分钟公式）。
- 全部四舍五入取整；变异不影响经验；每次收获只给一次经验，与份数无关。
