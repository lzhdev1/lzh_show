# 第二十三轮：冲刺、跳跃与土丘修复

## 问题

1. 手机点「冲刺」后没有真正加速，按钮文字还会和实际状态不一致。
2. 冲刺按钮位于摇杆右侧，容易和摇杆的手指打架。
3. 跳跃峰值 0.42m 偏低，跨土丘和石块的观感不够。
4. 野外土丘是 `SphereGeometry(..., 0, PI/2)` 半球，太像光滑的绿色罩子；部分石头是扁盒 / 圆柱，像平板。

## 冲刺修复

- 新增 `src/game/input.ts` 外部 store：`sprintEnabled()`、`subscribeSprint()`、`setSprintEnabled()`。
- 按钮与移动循环共用 `farmInput.sprint`。玩家移动条件为 `keys.has("shift") || farmInput.running || farmInput.sprint`。
- `releaseTouchInput()` 与 `releaseStick()` 不再把 `running` 清回 false，而是 `farmInput.running = farmInput.sprint`。打开面板、切后台、失焦只会松开摇杆，不会悄悄关掉冲刺。
- `FieldControls` 的 `TouchControls` 改用 `useSyncExternalStore(subscribeSprint, sprintEnabled)`，按钮文字、`aria-pressed` 和移动状态读同一个开关，不再依赖本地 state。
- `MobileControls` 卸载时调用 `setSprintEnabled(false)`。

## 按钮位置

- 竖屏：`left: max(18px, safe) + 25px`，`bottom: 186px + safe`，位于摇杆正上方居中。
- 横屏：`left + 19px`，`bottom: 176px + safe`。
- 390×844 实测按钮矩形：`left 43 / top 608 / 50×50`；点击后文字「冲刺 → 常速」，`aria-pressed` 同步；再点恢复。

## 跳跃

- `src/scene/player.ts` 峰值公式改为 `4 * 0.72 * air * (1 - air)`，峰高 0.72m。
- 起跳 0.24s、滞空 0.58s、落地缓冲 0.40s 不变。
- 390×844 点击跳跃键 0.53s 截图，人物明显离地约 0.7m，落地无穿地。

## 土丘

- 删除半球 `SphereGeometry`，新增 `createMoundGeometry(radius, height, seed)`：9 环 × 22 段。
- 椭圆足迹 `stretch 0.84–1.0`，外圈半径叠 3/5/8 频起伏；坡面叠肩部与细碎起伏。
- 剖面 `smoothstep` 后开 0.8 次方：坡脚切线归零、平缓接地面，坡顶圆缓而不是平台。
- 顶点色混 `草深 / 草中 / 草干` 三档绿，并在上坡若干扇区露裸土；`vertexColors + flatShading`。
- 每丘 11 簇深绿草簇，按同一剖面落位。
- 34 丘半径 1.5–3.8m、高 0.45–1.7m；碰撞半径 `radius * 0.99`。

## 石头

- 删除十二面体 / 八面体 / 圆柱 / 扁盒 / 球体随机拼装，改 `createRockGeometry(seed)`：二十面体按顶点坐标做三频扰动，下半压扁，46 块各自不同轮廓。
