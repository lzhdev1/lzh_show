## 这版验证了什么

- **不改正式 TTFarm**，只复用 `project/TTFarm/src/scene/professionalModels/horse.glb` 的骨架与 idle/run 动画。
- 马体：黑曜石底色 + Canvas 程序化熔岩裂纹（`emissiveMap`）+ 边缘呼吸。
- **马毛**：鬃毛保留 120 根颈脊逐根发丝；**原模型细长秃尾已从身体网格中裁掉**（`Celt_Horse` 顶点着色器按 `abs(x)<0.14 / y<1.62 / z<-0.62` 区域 `discard`，不再只靠隐藏 `Horse_Tail4`）。尾巴改为 **3 层长毛贴片 + 60 根尾根发丝**，根点抬到臀顶，贴片使用程序化透明长毛纹理，带 `uTime/uWind` 顶点摆动，吃风时梢部会软摆。
- **尾毛火焰直接叠在毛尾巴上**：每层毛片后面再叠一层 Additive 的同形火焰片（共享毛纹理、橙色、透明度呼吸），同时保留原有尾根体积火；尾巴本体不再是一束黑细线，而是“毛 + 火”的一体。
- 鬃尾火焰：以骨骼链 + 蒙皮顶点共同锚定；主火是 **6 层交叉体积切片**，片元用 3D fbm 噪声 + 高频侵蚀 + 火舌破碎生成，带风场弯曲 `uWind`。单层不透明度 `uOpacity 0.098`、切片高度 `0.64`。
- **参考图火焰纹理卡片已彻底关闭**，不再用贴图卡片表现主火形，避免出现“固体火片”的硬边。
- 软火粒子层沿鬃尾上升并受风偏移；奔跑时风速提高到 `1.35 ± 0.32`，火焰和粒子明显向后拖。另有蹄火、地面光斑、GPU 余烬、HDR + 选择性 Bloom。
- 256 根骨骼、3 个 SkinnedMesh、4 段动画均正常加载，静立与奔跑切换时火焰、马毛都跟随骨骼。URL 追加 `&anim=run` 可直接以奔跑姿态打开。

## 当前完成度与边界

相对参考图，当前约 **85%**：

- ✅ 黑曜石马体、熔岩裂纹、鬃尾气体火、马毛、蹄火、余烬、整体氛围已成立；火舌有柔边、有湍流、会随风弯曲。
- ⚠️ 主火是“6 层交叉切片 + 3D 噪声”的 2.5D 近似，近看仍有分层，火焰不会真正卷曲成连续体积。
- ⚠️ 去掉纹理卡片后，火焰细节和“火舌尖”弱于参考图，整体更接近热气流/火雾；若要同时保留真实火舌细节，需要换 flipbook 或 raymarch。
- ⚠️ 尾巴目前是 3 层透明毛片 + 60 根发丝，不是真正逐根卷曲毛发；近看仍是分层毛片，后续可加卷曲噪声和 5–7 组发束。
- ⚠️ 马体裂纹比参考图细，腹部/腿部的大面积熔岩需要再加一层低频熔岩遮罩。

## 继续提升的代价

- **预渲染 flipbook**：用 Blender/EmberGen 烘 24–32 帧循环火焰序列，运行时滚动 UV；观感可到参考图 85–90%，但需要美术资产与显存。
- **Raymarch 体积火**：观感最高，移动端/网页多端成本高，不建议直接上正式农场。
- 实时版继续调：增加低频熔岩遮罩、尾焰沿骨骼外扩的程序化曲线、风向/阵风强度；可到 80–85%，但仍是近似。
